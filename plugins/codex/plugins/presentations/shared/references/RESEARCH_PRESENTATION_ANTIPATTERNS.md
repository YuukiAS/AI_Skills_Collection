# Research Presentation Anti-Patterns

These failures must be checked during planning and rendered QA.

| Anti-pattern | Why it fails | Required response |
|---|---|---|
| title + slogan + giant empty table | Creates structure without variables, units, or values. | Delete the table or add real comparison axes and evidence. |
| rounded-card dashboard | Turns causal or evidential relations into equal-looking boxes. | Use cards only when objects are truly parallel and independently comparable. |
| consulting language | Words like strategic pillar, unlock, and key lever do not map to testable hypotheses. | Replace with question, hypothesis, observation, estimate, failure, or decision. |
| generic arrows without scientific objects | The slide does not say what quantity or object changes. | Nodes must be samples, data, images, variables, models, estimands, or operations. |
| fake visualization | Shapes do not encode data, mechanism, uncertainty, or comparison. | Decorative objects do not count as visual evidence. |
| paragraph pasted onto slide | The relation requires reading long prose. | Extract entities, comparisons, and causal relations, then redraw. |
| unreadably shrunk paper figure | Journal figure panels, axes, and legends fail at presentation distance. | Crop/recompose without changing data meaning; enlarge axes and key labels. |
| every slide using same layout | Different scientific objects are forced into one topology. | Let object relationship determine layout. |
| decorative icons replacing evidence | Icons do not prove cohort, lesion, prediction, or mechanism. | Prefer real figure/image/mechanism; keep icons secondary if used at all. |
| vague next steps | The next action has no information value. | Bind next work to current uncertainty and a discriminating readout. |
| internal planning language leaking onto slide | Backlog, handoff, evidence class, route promotion, and ticket language are not scientific content. | Translate into scientific state and speaker notes. |
| evidence-free roadmap | Phase labels have no experiment, dependency, or decision. | Tie each node to a real deliverable and evidence dependency. |
| pooled multi-center result | A single mean can hide center/protocol/pathology degradation. | Check center, vendor, protocol, subgroup, and tail-risk views. |
| success-only research update | Advisor cannot see the decision-relevant problem. | Actively include failures, contradictions, stop decisions, and uncertainty. |

Scientific QA must fail a slide that relies on these patterns to replace missing evidence.
