# 学生材料制作顺序

新建作业、项目简报、讲义或普通检查表时读取本文件。它把内容创作与机械制作连接起来，保留 v0.1 的轻量流程。

## 1. 准备来源

- 确定课程负责人提供的题目、数据、学习目标、公开分值、截止要求和方法边界。
- 区分学生可见材料、教师或考官材料、制作说明和执行证据。
- 有接受稿时记录 `accepted_base`；新稿保持候选身份。
- 记录本轮 `edit_scope`、精确项、已拒绝内容和需要保持的关系。

## 2. GPT 完成正文

1. 按 `RA-01` 和 `RA-06` 写清学生任务、必要背景、产出与公开规则。
2. 按 `RA-07` 调用 Content Selection 的 `CS-03`～`CS-07`，形成唯一内容计划。
3. 按 `RA-08` 调用 Clear Writing 的 `CW-03`～`CW-08`、`LF-*`，修订旧稿时再应用 `FI-*`。
4. 按 `RA-11` 标记文档家族、题目与说明的相邻关系、连续区域和分页约束。
5. 复读完整学生正文，确认没有混入答案、内部评分逻辑、制作记录或其他读者专属材料。
6. 填写本次执行证据中的内容规则和成品位置。

## 3. 交给 Codex 制作

GPT 填写 handoff，绑定确定正文、来源、候选身份、允许改动、语义块、目标文件和执行证据。Codex 按 `RA-12`～`RA-14` 渲染、机械检查、打包、发布与回读。制作冲突需要改变内容或语义布局时，携带文件与页面证据返回 GPT。

## 4. GPT 查看成品

取得全部目标页面和机械结果后，GPT 应用 `CS-08`、`CS-09` 查看完整作品，检查学生任务是否清楚、信息层级是否正确、删改是否引出版式问题。需要文字返修时继续调用 Clear Writing，并更新同一执行证据文件。
