# 快速傅里叶变换：定义和速度

快速傅里叶变换（Fast Fourier Transform, FFT）是快速计算序列的离散傅里叶变换（DFT）或其逆变换的方法。傅里叶分析将信号从原始域（通常是时间或空间）转换到频域表示，或执行反向转换。FFT 通过把 DFT 矩阵分解为稀疏因子之积来加速此类变换，因此能够将按 DFT 定义直接计算所需的复杂度从 `O(n^2)` 降低到 `O(n log n)`，其中 `n` 是数据大小。

快速傅里叶变换广泛应用于工程、科学和数学领域。其基本思想在 1965 年得到普及，但早在 1805 年就已被推导出来。1994 年，美国数学家 Gilbert Strang 将 FFT 描述为“一生中最重要的数值算法”之一，它也被 IEEE 科学与工程计算期刊列入 20 世纪十大算法。

用 FFT 计算 DFT 会得到与直接按 DFT 定义计算相同的结果；最重要的区别是 FFT 更快。由于舍入误差的存在，许多 FFT 算法还会比直接运用定义求值更精确。

令 `X_0, ..., X_{N-1}` 为复数。DFT 由下式定义：

```text
X_k = sum_{n=0}^{N-1} x_n e^{-i 2π k n / N},  k = 0, ..., N-1.
```

直接按这个定义求值需要 `O(N^2)` 次运算：`X_k` 共有 `N` 个输出，每个输出需要 `N` 项求和。直接使用 DFT 运算时，每个输出需要 `N` 个复数乘法和 `N-1` 个复数加法，因此计算所有 `N` 点的值需要 `N^2` 个复数乘法和 `N^2-N` 个复数加法。FFT 则指任何能够在 `O(N log N)` 次操作中计算出相同结果的方法。更准确地说，所有已知的 FFT 算法都需要 `O(N log N)` 次运算，虽然目前还没有已知证据证明更低复杂度不可能。

要说明 FFT 节省时间的方式，可以考虑复数相乘和相加的次数。直接计算 DFT 的值涉及 `N^2` 次复数相乘和 `N(N-1)` 次复数相加；通过削去乘以 1 等琐碎运算，可节省 `O(N)` 次运算。众所周知的基 2 Cooley-Tukey 算法在 `N` 为 2 的幂时，可以只用 `(N/2) log_2 N` 次复数乘法和 `N log_2 N` 次加法得到相同结果。在实践中，现代计算机的实际性能通常不只由算术运算速度决定，但从 `O(N^2)` 到 `O(N log N)` 的总体改进仍然非常重要。
