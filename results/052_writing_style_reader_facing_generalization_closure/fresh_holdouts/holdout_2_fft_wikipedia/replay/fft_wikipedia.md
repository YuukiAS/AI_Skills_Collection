# 快速傅里叶变换：定义和速度

快速傅里叶变换（Fast Fourier Transform，FFT）是一类快速计算序列的离散傅里叶变换（DFT）及其逆变换的方法。傅里叶分析可以把信号从原始域转换到频域，也可以进行反向转换；原始域通常是时间域或空间域。FFT 将 DFT 矩阵分解为稀疏因子的乘积，从而加快计算。对于大小为 `n` 的数据，直接按 DFT 定义计算的复杂度是 `O(n^2)`，而 FFT 将其降到了 `O(n log n)`。

FFT 与直接按定义计算 DFT 得到的结果相同，主要区别在于 FFT 更快。不过，实际计算会受到舍入误差的影响，因此许多 FFT 算法还可能比直接按定义求值更精确。

用 `X_0, ..., X_{N-1}` 表示 DFT 的复数输出，其定义为：

```text
X_k = sum_{n=0}^{N-1} x_n e^{-i 2π k n / N},  k = 0, ..., N-1.
```

这里共有 `N` 个输出 `X_k`，每个输出都需要对 `N` 项求和。直接按定义计算一个输出，需要 `N` 次复数乘法和 `N-1` 次复数加法；计算全部 `N` 个输出，就需要 `N^2` 次复数乘法和 `N^2-N` 次复数加法。加法次数也可以写成 `N(N-1)`。因此，直接计算 DFT 需要 `O(N^2)` 次运算。即使省去乘以 1 之类的简单运算，也只能减少 `O(N)` 次运算。

FFT 则泛指能用 `O(N log N)` 次运算求出相同结果的方法。更准确地说，所有已知 FFT 算法的运算复杂度都是 `O(N log N)`，但目前还没有证明表明更低的复杂度不可能实现。

常见的基 2 Cooley-Tukey 算法可以具体说明 FFT 节省了多少计算：当 `N` 为 2 的幂时，它只需 `(N/2) log_2 N` 次复数乘法和 `N log_2 N` 次加法，就能得到相同结果。现代计算机的实际性能通常还受算术运算速度以外的因素影响，但从 `O(N^2)` 降到 `O(N log N)`，仍然是很重要的改进。

FFT 广泛应用于工程、科学和数学领域。它的基本思想早在 1805 年就已被推导出来，并在 1965 年得到普及。1994 年，美国数学家 Gilbert Strang 将 FFT 称为“一生中最重要的数值算法”之一；IEEE 科学与工程计算期刊也将它列入了 20 世纪十大算法。
