# Python `re` 模块：正则表达式操作

`re` 模块提供与 Perl 类似的正则表达式匹配操作。模式和待搜索的字符串都可以使用 Unicode 字符串（`str`）或 8 位字节串（`bytes`），但两者的类型必须一致：不能用字节串模式匹配 Unicode 字符串，也不能用 Unicode 字符串模式匹配字节串。执行替换时，替换字串也必须与模式、待搜索字符串的类型一致。

编写正则表达式时，需要留意反斜杠在两处的含义。正则表达式用反斜杠（`'\'`）表示特殊形式，也用它让特殊字符按字面含义匹配。Python 字符串字面值同样用反斜杠进行转义，这两层用法会发生冲突。例如，要匹配一个反斜杠，正则表达式本身需要写成 `\\`；而在普通 Python 字符串字面值中，每个反斜杠又要写成 `\\`，所以代码中最终要写成 `'\\\\'`。

如果 Python 字符串字面值中出现无效的转义序列，目前会产生 `SyntaxWarning`，未来则会引发 `SyntaxError`。即使某个转义序列在正则表达式中有效，只要它在 Python 字符串字面值中无效，也会受到这一规则的影响。

使用 Python 的原始字符串表示法，可以避免字符串字面值这一层的额外转义。原始字符串以 `r` 为前缀，反斜杠不需要做上述特殊处理。例如，`r"\n"` 包含反斜杠和字母 `n` 两个字符，而 `"\n"` 只包含一个换行符。因此，在 Python 代码中，正则表达式模式通常用原始字符串书写。

绝大多数正则表达式操作既可以通过模块级函数调用，也可以通过已编译正则表达式对象的方法调用。模块级函数是快捷方式，使用时不需要先编译正则表达式对象，但也会失去一些用于微调的参数。

第三方模块 `regex` 提供与标准库 `re` 兼容的 API，并提供附加功能和更全面的 Unicode 支持。
