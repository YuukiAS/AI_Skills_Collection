# Python `re` 模块：正则表达式操作

`re` 模块提供正则表达式匹配操作，用法与 `Perl` 类似。

正则表达式模式和待搜索的字符串都可以使用 Unicode 字符串（`str`）或 8 位字节串（`bytes`），但两者的类型必须一致。Unicode 字符串不能与字节串模式匹配，字节串也不能与 Unicode 字符串模式匹配。执行替换时，替换字串还必须与模式、待搜索字符串保持相同的类型。

编写模式时，反斜杠的处理容易让人混淆。正则表达式用反斜杠（`\`）表示特殊形式，也用它让特殊字符按字面含义匹配。Python 字符串字面值同样用反斜杠进行转义，因此两套规则会发生冲突。例如，要匹配一个反斜杠，正则表达式需要写成 `\\`；如果用普通 Python 字符串字面值表示这个模式，每个反斜杠又需要写成 `\\`，所以代码中最终要写成 `'\\\\'`。

Python 字符串字面值中的无效转义序列目前会产生 `SyntaxWarning`，未来则会引发 `SyntaxError`。即使某个转义序列在正则表达式中有效，只要它在 Python 字符串字面值中无效，也会受到这一规则的影响。

使用 Python 的原始字符串表示法，可以避免在字符串字面值这一层为反斜杠额外转义。原始字符串在字面值前加 `r` 前缀，其中的反斜杠不需要做特殊处理。例如，`r"\n"` 包含反斜杠和字母 `n` 两个字符，而 `"\n"` 只包含一个换行符。Python 代码中的正则表达式模式通常采用原始字符串表示法。

绝大多数正则表达式操作既可以通过模块级函数调用，也可以通过已编译正则表达式对象的方法调用。模块级函数是快捷方式，使用时不必先编译正则表达式对象，但会少一些可用于微调的参数。

第三方模块 `regex` 提供与标准库 `re` 模块兼容的 API，并提供额外功能和更全面的 Unicode 支持。
