# 原文片段

The microservice batches requests for up to 40 ms before sending them to the
embedding model. This reduces per-request overhead, but it can increase tail
latency when traffic is sparse. The deployment uses the `text-embedding-3-small`
model and logs only aggregate queue length, not raw user text.

The source page also contains an archive banner, duplicate navigation links, and
a maintenance note saying that examples were last regenerated by the docs build
system. Those page-management details are not part of the service behavior.

# 改写稿片段

该微服务会先把请求攒成批次，再送入 embedding model。这样通常能减少每次请求的开销，但在请求很少时，等待批次会让尾延迟变高。当前部署使用 `text-embedding-3-small`，日志只记录队列长度汇总，不记录用户原文。
