# Frontend Design Candidate Replay Task

Use the installed `web-development@ai-skills-candidate` plugin through its normal Frontend Design entry.

Do not answer from this task file alone. Load the plugin's generated normal entry, then record the route you used.

For each scenario in `scenarios.json`:

1. Start from the normal Frontend Design entry.
2. Read the coordinator source before any delegate source.
3. Decide the task scale, design authority, target surface, and required delegates.
4. Record which delegate sources were consumed.
5. Give a concise production routing/admission decision.
6. Keep the response repo-safe and do not modify any external project.

Output one section per scenario with:
