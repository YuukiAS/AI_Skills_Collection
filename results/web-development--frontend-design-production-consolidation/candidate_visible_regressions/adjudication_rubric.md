# Frontend Design Coordinator Regression Rubric

This rubric is not included in candidate-visible prompts.

## Expected Coverage

- `s1_browser_tiny_spacing_fix`: light S1 path, current production grammar, no forced Figma or independent review unless a larger gap appears.
- `s2_durable_authority_settings_panel`: bounded S2 path, product states and design-system extension only where needed.
- `s3_no_figma_product_redesign`: S3 path, no-Figma is valid through durable authority, full P0-P4 closure.
- `canonical_figma_material_change`: Figma is canonical authority; material design mismatch returns to Figma/design convergence, not code-only drift.
- `native_handoff_action_reachability`: native surface boundary plus safe action reachability to the user-only folder choice boundary.
- `competing_route_interaction_claim`: stronger causality evidence is needed because two routes can cause the same final state.
- `unsupported_metric_ranking_semantic_claim`: product UX owns visible metric/ranking semantics; styling cannot invent unsupported priority.
- `implementation_drift_should_not_change_design`: implementation drift should repair code/tokens without changing accepted design source.

## PASS Standard

A candidate response passes only if it enters the generated Frontend Design coordinator first, records selected delegate sources, classifies scale, authority, and surface, and binds any producer verdict to exact evidence rather than source prose alone.
