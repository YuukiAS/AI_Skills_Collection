# Neutral Workflow Scenario Review

Use the installed Verified Workflow candidate through the normal plugin entrypoint.
Read the scenario facts in `inputs/01-workflow_core_scenarios.json`.
For each scenario, write a concise practitioner response to `outputs/response.md`.

For each scenario, cover:

- how the current situation should be handled;
- the next action;
- what can and cannot be claimed now;
- the basis for that conclusion.

Do not assume access to private repositories or live host state. Do not perform network actions.
