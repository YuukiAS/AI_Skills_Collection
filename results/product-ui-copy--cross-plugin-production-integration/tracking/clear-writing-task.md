# Clear Writing Review Task

Use the currently installed Clear Writing / writing-style plugin to improve the reader-facing GitHub Issue copy in the input file.

Constraints:

- Preserve every exact locator, branch name, commit SHA, issue number, lifecycle status, file path and source entry title.
- Preserve the fixed section labels: `问题：`, `当前进度：`, `当前执行锚点：`, `下一步：`.
- Do not change source maturity, Project Status, Area, `tracking: #N`, required-consumer truth, evidence meaning, or Resolution commit.
- Do not add PR, release, merge, or closure claims.
- Return two final Issue titles and bodies, one for Frontend Design and one for Clear Writing.
