# 布隆过滤器：原理、实现与使用限制

布隆过滤器（Bloom Filter）是一种节省存储空间的概率数据结构，用于判断某个元素是否属于一个集合。它由伯顿·霍华德·布隆（Burton Howard Bloom）于 1970 年提出（Bloom，1970）。它不保存元素本身，而是用散列函数把元素映射到位数组中。

布隆过滤器的查询结果有两种：**一定不在集合中**，或**可能在集合中**。在标准的、只添加元素而不清除位的用法下，它不会漏报已经加入的元素，但可能把未加入的元素误判为存在。这种误报称为假阳性，漏报则称为假阴性。

## 如何插入和查询

一个空布隆过滤器包含长度为 \(m\) 的位数组，所有位初始为 0；另有 \(k\) 个散列函数，每个函数都将元素映射到数组中的一个位置。理想情况下，这些函数相互独立，并在 \(m\) 个位置上均匀分布。\(k\) 通常是较小的常数，其选择取决于期望的误报率 ε；位数组长度 \(m\) 则随 \(k\) 和预计加入的元素数量按比例配置。

插入和查询使用同一组散列函数：

1. **插入元素**：计算它对应的 \(k\) 个数组位置，将这些位置的位全部设为 1。
2. **查询元素**：计算同样的 \(k\) 个位置。只要其中有一位为 0，就能确定该元素不在集合中；如果全部为 1，则只能判断它可能在集合中。

零位之所以能排除一个元素，是因为该元素若曾被插入，其对应位就都应已设为 1。反过来，全为 1 并不能证明元素存在：其他元素也可能碰巧将这些位全部置为 1。基本布隆过滤器无法区分这两种情况，需要更进一步的技术来处理。

例如，用长度 \(m=18\) 的位数组和 \(k=3\) 个散列函数表示集合 \(\{x,y,z\}\)。每个元素都对应 3 次散列映射。如果查询元素 \(w\) 时，其中一个映射位置仍为 0，就可以确定 \(w\) 不属于该集合。

## 如何构造多个散列函数

当 \(k\) 较大时，构造 \(k\) 个不同且独立的散列函数并不容易。实现时可以从一个或少数几个散列函数出发，生成所需的位置：

- 如果一个散列函数的输出足够宽，而且不同位段之间几乎没有相关性，可以把输出切分成多个位段，分别用于生成位置。
- 如果散列函数接受初始值，可以依次使用 `0, 1, ..., k − 1` 作为不同的初始值。
- 也可以把这些值加入或追加到键中，再进行散列。

对于较大的 \(m\) 和／或 \(k\)，可以放宽散列函数之间的独立性要求，而误报率的增加可以小到忽略不计；这一点可参见 Dillinger 与 Manolios（2004a）以及 Kirsch 与 Mitzenmacher（2006）。

Dillinger 与 Manolios（2004b）展示了利用增强双重散列和三重散列生成 \(k\) 个索引的有效性。这两种方法都是双重散列的变体，实质上用两个或三个散列值作为种子，通过简单的随机数生成器导出所需索引。

## 为什么删除困难

基本布隆过滤器无法安全地删除单个元素。多个元素可能共用同一位，位数组又没有记录某一位由哪些元素置为 1。因此，将目标元素对应的任意一位清零，虽然足以使它不再通过查询，却也可能让其他仍在集合中的元素查询失败，造成漏报。

一种模拟删除的方法是另设一个“移除过滤器”，专门记录已删除的元素。但辅助过滤器也可能误报：如果它把一个未删除的元素误判为已删除，两个过滤器组合后的查询就会产生漏报。这种方法还无法直接重新添加已删除的元素，因为必须先从移除过滤器中删除相应记录，又回到了同一个删除难题。

如果所有键仍可获取，误报率过高时可以重新生成过滤器。不过，枚举这些键可能代价很高，例如需要多次读取磁盘，因此重建应是相对少见的操作。

## 时间、空间与适用边界

链表、树和散列表通常需要保存元素本身，存储需求会随着元素数量增加而增长。常见的查询复杂度比较如下，其中 \(n\) 表示元素数量：

| 数据结构 | 查询时间复杂度 |
| --- | --- |
| 链表 | \(O(n)\) |
| 树 | \(O(\log n)\)，取决于树的组织方式 |
| 散列表 | 通常为 \(O(1)\) |
| 布隆过滤器 | \(O(k)\)，以单次散列计算和位访问为常数成本 |

布隆过滤器的插入和查询都处理 \(k\) 个散列位置，时间复杂度为 \(O(k)\)；当 \(k\) 固定时，可视为常数时间。总存储空间则由位数组长度决定：数组占用 \(m\) 位，空间复杂度为 \(O(m)\)。单次操作涉及的位数与整个数组的大小需要分开计算。

布隆过滤器不保存元素本身，因此能节省空间，也在某些保密要求严格的场合具有优势。独立的散列计算还便于用硬件并行实现。

它的主要代价是误报：在过滤器参数不变时，加入的元素越多，误报率越高。针对降低误报率的研究已产生多种布隆过滤器变体。如果集合中的元素很少，直接使用散列表可能已经足够。
