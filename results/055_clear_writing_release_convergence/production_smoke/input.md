# 临时质控说明

我们在 8 个样本的小型 RNA 质控脚本中发现，过滤阈值会影响后续聚类解释。脚本不是新算法，只是把公开数据整理成统一对象。当前目标是确认质控步骤是否稳定，不比较模型性能。

复现命令：

```bash
python scripts/qc_rna.py --input data/raw/demo.h5ad --output data/processed/demo_qc.h5ad --min-genes 300 --max-mito 0.18
```

目前只检查了 8 个样本、约 12,000 个细胞。`--max-mito 0.18` 比 `0.25` 多移除约 6% 的细胞，其中多数来自同一批次。这个结果提示后续需要分开报告批次差异和线粒体比例，不能说严格阈值一定改善聚类。

下一步仍需在完整队列上重复阈值扫描。
