# RNA 质控阈值说明

在 8 个样本的小型 RNA 质控脚本中，我们观察到过滤阈值会影响后续聚类结果的解释。该脚本不是新算法，而是用于把公开数据整理成统一对象；当前目标是确认质控步骤是否稳定，不做模型性能比较。

复现命令如下：

```bash
python scripts/qc_rna.py --input data/raw/demo.h5ad --output data/processed/demo_qc.h5ad --min-genes 300 --max-mito 0.18
```

目前检查范围仅包括 8 个样本、约 12,000 个细胞。与 `--max-mito 0.25` 相比，`--max-mito 0.18` 会多移除约 6% 的细胞，而且这些细胞多数来自同一批次。

因此，现阶段只能说明线粒体比例阈值可能与批次差异共同影响质控结果。后续报告需要把批次差异和线粒体比例分开说明，不能直接得出“更严格的阈值一定改善聚类”的结论。

下一步仍需在完整队列上重复阈值扫描。
