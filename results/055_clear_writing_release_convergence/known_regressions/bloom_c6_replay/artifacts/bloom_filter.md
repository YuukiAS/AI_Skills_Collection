# 布隆过滤器

布隆过滤器（Bloom Filter）是一种用于判断元素是否属于某个集合的概率数据结构，由伯顿·霍华德·布隆（Burton Howard Bloom）于 1970 年提出。[Bloom, 1970] 它通过一系列散列函数把元素映射到二进制位数组中，具有很高的空间效率，查询效率也远超一般算法。不过，这种判断可能产生假阳性（误报），不会产生假阴性（漏报），而且简单布隆过滤器难以删除元素。

判断集合中是否存在某个元素，通常可以先保存所有元素，再通过比较进行检索。链表、树和散列表都采用这种思路；散列表也叫哈希表。随着元素增多，保存整个集合所需的空间越来越大，检索也可能变慢。这三种结构的检索时间复杂度分别为 $O(n)$、$O(\log n)$ 和 $O(1)$。布隆过滤器则不需要保存元素本身，而是利用位数组记录散列映射的结果。

## 位数组如何完成查询

一个空布隆过滤器包含长度为 $m$ 的位数组，所有位初始都为 0，并配备 $k$ 个不同的散列函数。每个函数都把元素映射到数组中 $m$ 个位置之一。为了取得最佳效果，这些函数应当相互独立，映射结果应服从均匀分布。通常，$k$ 是一个较小的常数，由期望的假阳性率 $ε$ 决定；$m$ 则与 $k$ 和待添加的元素数量成正比。

添加元素时，分别用这 $k$ 个散列函数计算它在数组中对应的位置，再把这些位置全部设为 1。查询时也计算同样的 $k$ 个位置：只要其中有一位为 0，就可以确定该元素不在集合中，因为一个已经添加的元素所对应的位都应当是 1。

如果这些位置全为 1，就只能判断该元素可能在集合中。这些位也可能是在添加其他元素时碰巧被设为 1，从而造成假阳性。简单布隆过滤器无法区分这两种情况，更先进的技术则可以处理这一问题。因此，简单布隆过滤器可能产生假阳性，但不会产生假阴性。

例如，表示集合 $\{x,y,z\}$ 的一个布隆过滤器可以取 $m = 18$、$k = 3$，即使用 18 位数组和 3 个散列函数。示意图中的彩色箭头表示各元素经散列后对应的数组位置，箭头数量表示散列函数的个数。元素 $w$ 至少映射到一个值为 0 的位置，因此可以确定它不属于集合 $\{x,y,z\}$。

## 散列函数的实现

当 $k$ 较大时，设计 $k$ 个不同且独立的散列函数并不容易。一个输出位数较多、质量良好的散列函数，其输出中不同位域之间应当几乎没有相关性，因此可以把输出切分成多个位域，用来生成多个“不同”的散列函数。另一种办法是使用一个接受初始值的散列函数，分别传入 $k$ 个不同的初始值，例如 $0, 1, \ldots, k-1$；也可以把这些值加入或追加到键中。

当 $m$ 和/或 $k$ 较大时，可以放宽散列函数之间的独立性要求，由此增加的假阳性率可以忽略不计。[Dillinger 与 Manolios, 2004a; Kirsch 与 Mitzenmacher, 2006] Dillinger 与 Manolios 还展示了用增强双重散列和三重散列导出 $k$ 个索引的有效性。[Dillinger 与 Manolios, 2004b] 这两种方法都是双散列的变体，实际上相当于以两个或三个散列值为种子的简单随机数生成器。

## 删除元素的限制

简单布隆过滤器无法直接移除元素，因为无法判断它对应的 $k$ 个位中，哪些位可以安全地清零。把其中任意一位设为 0，虽然足以让查询不再认为这个元素存在，却也会影响恰好映射到同一位置的其他元素。简单算法无法确认这些位是否还被其他已添加的元素使用，因此清除任何一位都可能引入假阴性。

可以引入一个辅助布隆过滤器，称为“移除过滤器”，记录已经移除的元素，以模拟一次性删除操作。但辅助过滤器也可能产生假阳性，而它的假阳性会变成原过滤器与移除过滤器组成的复合过滤器中的假阴性。这种方法还无法重新添加先前移除的元素：重新添加之前，需要先把它从移除过滤器中删除，于是又回到了同一个难题。

## 效率与假阳性率

与其他数据结构相比，布隆过滤器在空间和时间上都有很大优势，其存储空间和插入、查询时间都是常数量级（$O(k)$）。各散列函数互不依赖，便于用硬件并行实现。由于不必存储元素本身，布隆过滤器在保密要求非常严格的场合也有优势。

这些优势伴随着误报的代价：存入的元素越多，假阳性率就越高；如果元素数量很少，使用散列表就足够了。围绕降低假阳性率，已有不少研究，也由此产生了多种布隆过滤器变体。

在一种常见场景中，所有键，也就是待过滤的元素，都可以取得，但逐一枚举它们的代价较高，例如需要多次读取硬盘。当假阳性率过高时，可以重新生成过滤器，不过这种重建应当相对少见。
