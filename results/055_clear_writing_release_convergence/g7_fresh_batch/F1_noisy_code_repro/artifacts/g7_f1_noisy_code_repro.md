# 单细胞 RNA-seq 预处理的质控与复现

我们在一个小型单细胞 RNA-seq 预处理脚本中发现，过滤阈值和批次标签的处理方式会显著影响后续聚类的解释。当前实验旨在确认质控步骤是否稳定，不涉及模型性能比较。脚本本身也不是新算法，而是将下载的公开数据整理为统一的 AnnData 对象，便于比较不同的批次校正方法。

目前的检查仅覆盖 6 个供体、约 18,000 个细胞。与 `--max-mito 0.25` 相比，使用 `--max-mito 0.18` 会多移除约 7% 的细胞，其中一半以上来自同一个供体。这一观察提示，后续需要将供体差异与线粒体比例分开报告，不能据此认定更严格的阈值一定能改善聚类。

复现时，在项目根目录下运行：

```bash
python scripts/prepare_scrna.py \
  --input data/raw/pbmc_merged.h5ad \
  --output data/processed/pbmc_qc.h5ad \
  --min-genes 300 \
  --max-mito 0.18 \
  --batch-key donor_id
```

脚本先删除低质量细胞，再按 `donor_id` 写入批次标签。如果缺少 `donor_id`，脚本会停止，不会自动将所有细胞视为同一批次。

后续仍需在完整队列上重复阈值扫描，并将每个供体的保留细胞数列入补充表；这两项工作目前尚未完成。
