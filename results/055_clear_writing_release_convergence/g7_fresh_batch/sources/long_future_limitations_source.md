# 公共安全 fresh source 3：长文、future work、限制与归因

这份说明讨论一个多中心超声图像分割项目的阶段性结论。项目当前只完成了回顾性数据整理和第一轮内部验证，还没有进入前瞻性临床评估。所有结论都应保持为方法开发阶段的判断，不能写成已经证明临床有效。

数据来自 4 家医院的常规超声检查，共 1,240 张图像。每家医院使用的设备型号不同，图像深度和增益设置也不完全一致。我们把医院 A 和 B 作为训练来源，医院 C 作为调参验证来源，医院 D 只用于最终内部测试。这样的划分可以初步观察跨设备泛化，但不能代表真实部署，因为同一家医院内仍可能有不同操作者和不同检查协议。

模型方面，基线采用普通 U-Net，候选方法在编码器中加入轻量注意力模块，并使用相同的数据增强策略。候选方法在医院 D 上的 Dice 从 0.781 提高到 0.806，边界 Hausdorff 距离从 9.4 mm 降到 8.1 mm。这个改善有实际意义，但幅度不大，而且主要来自边界较清晰的病例。对于低对比度图像，候选方法仍会把声影区域误分为目标结构。

错误分析显示，失败病例大致分三类。第一类是探头角度导致目标结构只出现一部分，模型倾向于补全一个并不存在的完整轮廓。第二类是图像中存在强声影，候选方法会把声影边缘当作解剖边界。第三类是标注者之间本身存在分歧，尤其在目标结构边缘模糊时，两个专家的 Dice 只有约 0.84。这个标注不确定性意味着模型上限不能只用单一专家标签判断。

目前最重要的限制是评估仍然停留在回顾性内部数据上。医院 D 虽然没有参与训练，但仍来自同一个合作网络，采集协议和病种分布与训练医院相近。因此，当前结果不能证明模型已经适合跨地区部署，也不能证明它能减少医生阅片时间。它只能说明，在受控数据划分下，轻量注意力模块可能改善边界分割。

后续工作有三项。第一，需要邀请新的外部中心提供独立测试集，并在冻结模型后一次性评估，避免根据外部结果继续调参。第二，需要把失败病例按图像质量、操作者、设备型号和病灶类型分层，判断模型收益是否只集中在容易病例。第三，需要开展读片辅助实验，让医生在有无模型建议的条件下完成同一批病例，比较时间、交互次数和最终标注一致性。

这些后续工作目前都没有完成。报告可以建议优先做外部中心验证，但不能写成团队已经启动或已经完成。对于已有结果，合适的表述是“候选方法在内部测试中心显示出边界指标改善，但临床部署价值仍需独立外部验证和读片辅助实验确认”。
