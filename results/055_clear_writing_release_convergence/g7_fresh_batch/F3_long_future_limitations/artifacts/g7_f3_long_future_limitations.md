# 多中心超声图像分割的阶段性技术总结

多中心超声图像分割项目目前已完成回顾性数据整理和第一轮内部验证，尚未进入前瞻性临床评估。候选方法在内部测试中心显示出边界指标改善，但这一结果仍属于方法开发阶段的证据，临床部署价值还需独立外部验证和读片辅助实验确认。

本阶段数据来自 4 家医院的常规超声检查，共 1,240 张图像。各医院使用的设备型号不同，图像深度和增益设置也不完全一致。医院 A 和 B 的数据用于训练，医院 C 的数据用于调参验证，医院 D 的数据仅用于最终内部测试。按医院划分数据，可以初步观察模型的跨设备泛化表现。不过，同一家医院内仍可能存在不同操作者和检查协议，因此，这种划分尚不能代表真实部署条件。

实验以普通 U-Net 为基线，候选方法在编码器中加入轻量注意力模块，两者采用相同的数据增强策略。在医院 D 上，相较于基线，候选方法的 Dice 从 0.781 提高到 0.806，边界 Hausdorff 距离从 9.4 mm 降至 8.1 mm。这一改善对分割表现有实际意义，但幅度不大，且主要来自边界较清晰的病例。对于低对比度图像，候选方法仍会把声影区域误分为目标结构。

错误分析显示，失败病例大致涉及三类问题。探头角度可能使目标结构仅部分出现在图像中，此时模型倾向于补全一个并不存在的完整轮廓；强声影则可能使候选方法把声影边缘识别为解剖边界。另一类问题来自标注者之间的分歧：尤其在目标结构边缘模糊时，两位专家的标注 Dice 只有约 0.84。这种标注不确定性意味着，不能仅依据单一专家标签判断模型的性能上限。

当前评估最主要的限制仍是数据的回顾性和内部来源。医院 D 虽未参与训练，却与其他医院处于同一个合作网络，采集协议和病种分布也与训练医院相近。因此，现有结果只能支持这样的判断：在受控数据划分下，轻量注意力模块可能改善边界分割。它既不能证明模型已适合跨地区部署，也不能证明模型能够减少医生阅片时间。

要进一步判断这一改善能否推广，后续可优先考虑邀请新的外部中心提供独立测试集，并在模型冻结后进行一次性评估，避免根据外部测试结果继续调参。收益是否主要集中在容易病例，也需要通过更细的失败病例分析来检验：按图像质量、操作者、设备型号和病灶类型分层，才能进一步判断不同条件下的表现差异。

临床使用价值还需要读片辅助实验提供证据。后续需要让医生在有、无模型建议的条件下完成同一批病例，并比较所用时间、交互次数和最终标注一致性。外部中心验证、分层分析和读片辅助实验目前均未完成，仍是有待开展的工作。现阶段的结论应限于候选方法在内部测试中心显示出的边界指标改善，不能据此认定其已具有临床部署价值。
