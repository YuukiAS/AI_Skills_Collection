# 分组均值估计：已知事实

研究要估计多个学校各自的平均结果。学校 $j$ 有样本均值 $\bar y_j$ 和样本量 $n_j$。

完全合并把所有学校视为共享同一个均值，因此学校之间没有单独估计。完全分开则直接使用每所学校自己的 $\bar y_j$，不从其他学校借用信息。

部分合并使用分层模型。为建立直觉，可以把学校 $j$ 的估计写成：

$$
\hat\theta_j=w_j\bar y_j+(1-w_j)\mu,
$$

其中 $\mu$ 是总体中心，$w_j$ 由该校数据量和组内噪声等信息决定。小样本或噪声较大的学校通常有较小的 $w_j$，估计会更多靠近总体中心；大样本且测量稳定的学校通常有较大的 $w_j$，估计更接近自己的样本均值。这种向总体中心移动的现象称为收缩。

例子：学校 A 只有 5 名学生，样本均值很高；学校 B 有 500 名学生，样本均值略高于总体中心。部分合并通常会更强地调整学校 A，而较少调整学校 B，因为学校 A 的极端均值更可能受抽样波动影响。

若学校确实来自可以共享信息的总体，部分合并可降低小样本组估计的方差。若学校分成性质完全不同、却未在模型中表示的群体，向同一总体中心收缩可能掩盖真实差异。输入没有给出模型拟合结果、先验设定、组内方差或模型检查，因此不能判断本次数据中哪种方法实际预测最好，也不能给出具体的 $w_j$。
