本次评估中，Temporal Fusion Transformer (TFT) 的平均绝对误差低于季节性均值基线，说明它在当前测试中的预测误差更小。不过，目前尚未进行跨季节测试，还不能据此判断 TFT 在全年都更好。

评估使用公开的用电负荷序列，以过去 24 小时的数据预测下一小时。训练集和测试集按建筑划分，同一栋建筑不会同时出现在两侧。这样可以考察模型在未参与训练的建筑上的预测表现。这里需要区分两类信息：一类是每条记录属于哪栋建筑，用于划分数据；另一类是模型从过去时间窗中保留的历史信息，用于预测。季节性均值的预测结果作为比较基线；从原始数据到最终指标的可追溯记录，则用于核查结果是如何得到的。

下一步运行以下评估命令：

```bash
python tools/evaluate.py --config configs/tft_public.yaml
```

配置中的精确值为 `split_mode=building_holdout`，评估指标输出到 `artifacts/tft_eval/metrics.json`。若要进一步判断模型是否在全年都有优势，还需要补充跨季节测试；现有材料没有说明上述命令已包含这项测试。
