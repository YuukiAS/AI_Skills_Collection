当前评估显示，`Temporal Fusion Transformer (TFT)` 的平均绝对误差低于季节性均值基线。不过，尚未进行跨季节测试，因此目前不能声称 `TFT` 在全年都更好。下一步先运行既定评估；要判断全年表现，还需要补充跨季节测试。

这次评估使用公开的用电负荷序列，以过去 24 小时的数据预测下一小时。训练集和测试集按建筑划分，确保同一栋建筑不会同时出现在两侧。这样划分是为了考察模型在未参与训练的建筑上的预测表现。

讨论中需要区分几个概念：记录所属的建筑，指每条记录来自哪一栋建筑；模型保留的历史信息，指它从过去时间窗中保留下来的信息；从原始数据到指标的可追溯记录，用于核查结果是如何得到的；基线结果则用于比较模型表现。本次比较采用的是季节性均值基线。

下一步运行以下命令，配置中的精确值为 `split_mode=building_holdout`，评估输出写入 `artifacts/tft_eval/metrics.json`：

```bash
python tools/evaluate.py --config configs/tft_public.yaml
```
