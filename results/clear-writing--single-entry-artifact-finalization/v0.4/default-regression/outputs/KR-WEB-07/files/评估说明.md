# 用电负荷预测评估说明

当前评估中，模型的平均绝对误差低于季节性均值基线，说明它在本次测试中的预测误差更小。不过，团队尚未进行跨季节测试，因此还不能据此声称模型在全年都更好。

这次评估使用公开的用电负荷序列，以过去 24 小时的数据预测下一小时的负荷，所用模型为 Temporal Fusion Transformer (TFT)。训练集和测试集按建筑划分，确保同一栋建筑不会同时出现在两侧。这里需要区分的是各条记录属于哪一栋建筑；模型利用的历史信息，则来自过去的时间窗。

比较时，季节性均值基线提供参照结果；从原始数据到最终指标的可追溯记录，则用于说明结果是如何得到的。这两者分别回答“模型表现如何”和“结果从何而来”。

下一步运行以下命令，配置中的精确值为 `split_mode=building_holdout`，输出写入 `artifacts/tft_eval/metrics.json`：

```bash
python tools/evaluate.py --config configs/tft_public.yaml
```

要判断当前优势能否延续到不同季节，还需要跨季节测试；现有记录没有说明上述命令会完成这项测试。
