# Shared Beamer core implementation

The course-standard and CUHK Beamer templates now use one 160 × 90 mm layout. Both remain editable as LaTeX. The shared core supplies colour, type and leading, the 8 mm body rail, title anchors, semantic spacing and components, navigation, footer, and closing. CUHK adds approved school artwork only on the title page.

- [Shared core](../../skills/tools/documents-media/presentations/shared/templates/_shared/beamer-core-v1/README.md) documents the component API. Its machine-readable layout contract is byte-identical to the frozen Planner YAML.
- [Course-standard](../../skills/tools/documents-media/presentations/shared/templates/course-standard/README.md) includes an editable starter and the 11-slide [reference PDF](../../skills/tools/documents-media/presentations/shared/templates/course-standard/reference.pdf).
- [CUHK](../../skills/tools/documents-media/presentations/shared/templates/cuhk/README.md) retains the four original PNGs and the `\usetheme{sintef}` import. The older convenience entry forwards to the canonical source. The skin uses the approved light artwork on the title page and adds no school chrome to body pages.
- [Template routing](../../skills/tools/documents-media/presentations/shared/template-routing.md) makes the blue standard Beamer the built-in default and selects CUHK only when explicitly requested. Supplied templates and requested editable formats still take precedence; PPTX/Slides remains on the editable presentation route.
- The CUHK research entry stages the same shared core and records its input hashes. Long display equations, source figures with captions, and paper interpretation pages use shared text flow and columns. Existing specialized quantitative and imaging layouts still use their scientific renderers inside the shared rail. The compatibility checks recognize the staged brand inputs as well as archived decks with the older title-background directive.

Both entry paths compiled from the generated plugin payload with XeLaTeX. The editable starter decks have 3 and 7 pages.
