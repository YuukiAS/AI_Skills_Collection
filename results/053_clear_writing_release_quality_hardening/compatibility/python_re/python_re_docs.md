# Python `re` 模块：正则表达式操作

`re` 模块提供正则表达式匹配操作，用法与 Perl 中的正则表达式类似。

模式和待搜索的字符串都可以使用 Unicode 字符串（`str`）或 8 位字节串（`bytes`），但两者的类型必须一致：字节串模式不能匹配 Unicode 字符串，Unicode 字符串模式也不能匹配字节串。执行替换时，替换字串也必须与模式、待搜索字符串使用相同的类型。

编写模式时，需要留意反斜杠在正则表达式和 Python 字符串字面值中的两层含义。正则表达式用反斜杠（`\`）表示特殊形式，也用它让特殊字符按普通字符处理；Python 字符串字面值同样用反斜杠进行转义，因此两套转义规则会发生冲突。例如，要匹配一个反斜杠，正则表达式本身需要写成 `\\`；如果用普通 Python 字符串字面值表示这个模式，其中的每个反斜杠又需要写成 `\\`，所以最终要写成 `'\\\\'`。

Python 字符串字面值中无效的转义序列目前会触发 `SyntaxWarning`，未来则会引发 `SyntaxError`。即使某个转义序列在正则表达式中有效，只要它在 Python 字符串字面值中无效，也会受到这一规则的影响。

为避免额外的转义，正则表达式模式通常使用 Python 的原始字符串表示法，也就是在字符串字面值前加上 `r` 前缀。在原始字符串中，反斜杠不需要再做转义处理。例如，`r"\n"` 包含反斜杠（`\`）和字母 `n` 两个字符，而 `"\n"` 只包含一个换行符。

绝大多数正则表达式操作既可以通过模块级函数调用，也可以通过已编译正则表达式对象的方法调用。模块级函数是快捷方式，使用时不需要先编译正则表达式对象，但会少一些可用于微调的参数。

第三方模块 `regex` 提供了与标准库 `re` 模块兼容的 API，并提供额外功能和更全面的 Unicode 支持。
