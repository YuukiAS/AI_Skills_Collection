# Python `re` 模块：正则表达式操作

`re` 模块提供正则表达式匹配操作，用法与 `Perl` 语言类似。

正则表达式模式和被搜索的字符串都可以使用 Unicode 字符串（`str`）或 8 位字节串（`bytes`），但两者的类型必须一致：字节串模式不能用于匹配 Unicode 字符串，Unicode 字符串模式也不能用于匹配字节串。执行替换时，替换字串也必须与模式、被搜索的字符串使用相同的类型。

编写模式时，需要留意反斜杠的两层转义。正则表达式用反斜杠（`'\'`）表示特殊形式，也用它让特殊字符按字面含义匹配。Python 字符串字面值同样用反斜杠进行转义，两套规则因此会发生冲突。例如，要匹配一个反斜杠，正则表达式本身需要写成 `\\`；如果用普通 Python 字符串字面值表示这个模式，每个反斜杠又要写成 `\\`，所以完整的字符串字面值是 `'\\\\'`。

Python 字符串字面值中的无效转义序列目前会产生 `SyntaxWarning`，将来会改为产生 `SyntaxError`。即使某个转义序列在正则表达式中有效，只要它在 Python 字符串字面值中无效，也会触发这一行为。

为避免 Python 字符串字面值带来的额外转义，正则表达式模式通常使用原始字符串表示法，也就是在字符串字面值前加上 `r` 前缀。这样，反斜杠就不必再做特殊处理。例如，`r"\n"` 包含反斜杠和字母 `n` 两个字符，而 `"\n"` 只包含一个换行符。

绝大多数正则表达式操作既可以通过模块级函数调用，也可以通过已编译正则表达式对象的方法调用。模块级函数是快捷方式，使用时不需要先编译正则表达式对象，但也会失去一些微调参数。

第三方模块 `regex` 提供与标准库 `re` 模块兼容的 API，并提供附加功能和更全面的 Unicode 支持。
