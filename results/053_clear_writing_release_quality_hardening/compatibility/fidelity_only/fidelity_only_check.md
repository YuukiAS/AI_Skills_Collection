# 事实保真风险检查

数字、公式、路径及适用条件均需要保护。主要风险是把仅用于 FedAvg 消融实验的正则项扩大为所有方法共享的设置，或把所报告的指标扩大为性能优势结论。本检查仅依据随附文本识别保真风险，未核验实验记录或代码；未改写正文。

| 检查项 | 需保护的内容 | 保真风险与边界 |
| --- | --- | --- |
| 数字与指标 | `FedAvg`、`Dice=0.81`、`HD95=7.4 mm` | 保留指标与数值的对应关系、小数精度及 `mm` 单位；不能互换指标、舍入数字或擅自改成百分比。原文未说明这些数值是均值、最佳值还是单次结果，不能补写统计含义。 |
| 实验条件 | “在同一划分设置下” | 必须与上述结果一同保留。不能据此补出具体数据集、划分比例，或推断其他训练设置也完全相同。 |
| 公式 | $\mathcal{L}=\mathcal{L}_{seg}+0.1\mathcal{L}_{reg}$ | 保护等号、加号、系数 `0.1`、下标 `seg` 和 `reg`，不得删项、改权重或擅自补充正则项的数学定义。 |
| 公式适用范围 | “这个正则项只用于 FedAvg 消融实验，不能写成所有方法共享设置” | 这是明确的范围限制，必须与公式绑定。不能泛化为全部 FedAvg 实验或全部方法的默认损失函数，也不能直接认定前述指标来自使用该正则项的消融实验。 |
| 训练脚本路径 | `scripts/train_fedavg.py` | 逐字保护目录、文件名、下划线及扩展名，并保留其“训练脚本”角色；原文列出路径不等于文件存在或已执行得到验证。 |
| 配置文件路径 | `configs/fedavg.yaml` | 逐字保护路径及 `.yaml` 扩展名，并保留其“配置文件”角色；不能换成其他配置文件，也不能据此推断文件中的实际参数。 |
| 结论强度 | 原文只报告条件下的指标及正则项适用范围 | 没有比较结果、显著性检验或正则项效果证据，不能增加“优于其他方法”“显著提升”“证明正则项有效”等结论；也不应无依据地把原文确定报告的数值改成猜测。 |

仅凭随附文本，尚不能确认数值的实验真实性、两个路径的实际内容，以及指标对应的实验是否使用了该正则项。这些是证据缺口，不是已发现的事实错误。
