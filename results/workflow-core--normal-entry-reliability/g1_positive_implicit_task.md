# Release Readiness Task

A repository maintenance branch has a frozen implementation candidate and a
published evidence branch. Decide whether the current state is ready for final
release closure, and write a concise release-readiness note to
`outputs/g1_positive_implicit_result.md`.

Use the normal process capability available in this runtime when a task has
explicit gates, branch identity, evidence artifacts, CI status, and release
boundaries. Do not access the network.
