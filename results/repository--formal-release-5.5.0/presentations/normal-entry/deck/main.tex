\section{Failure and uncertainty}
% P04
\begin{frame}{The motion-corrupted case remains unresolved}
\textbf{Observed failure}
\par\medskip
One motion-corrupted volume still has disconnected false positives under both methods.
\par\bigskip
\textbf{Interpretation limits}
\begin{itemize}
\item No confidence interval or repeated-seed estimate is available.
\item The observed improvement may depend on this small split.
\end{itemize}
\medskip
The result supports replication, not a superiority claim.
\end{frame}
