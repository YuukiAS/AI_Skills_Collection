# Manuscript Source Package

This compact package contains a preliminary LaTeX manuscript source prepared from `manuscript_notes.md`.

## Contents

- `paper.tex`: main manuscript source.
- `references.bib`: placeholder file marking citation support as pending; no external references are asserted.

## Production Status

The source is organized for downstream formal PDF production, but rendering and PDF QA are intentionally handed off rather than performed in this authoring-only step. The renderer or venue owner should verify layout, bibliography handling, table placement, and any venue-specific front matter before producing a final PDF.

## Evidence Boundary

The manuscript is limited to one internal validation split with 18 volumes. It preserves the supplied metrics and the known motion-corrupted failure case. It does not add external citations, datasets, reviewer comments, venue requirements, or additional experiments.
