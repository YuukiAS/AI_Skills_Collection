# C2 Development Replay Task

Use Research Authoring to prepare an advisor-facing research update from the
attached raw notes.

The user ultimately wants this update to become a formal PDF for an advisor
meeting, but this standalone Research Authoring surface does not have the
approved PDF renderer companion installed. Produce the stable scientific source
and a complete downstream production handoff for the renderer owner.

Save the outputs as:

- `advisor_update_source.md`
- `downstream_renderer_handoff.md`
- `route_receipt.md`

The report should be concise, evidence-backed, and useful to a PI deciding the
next experiment. Keep claims within the attached notes.
