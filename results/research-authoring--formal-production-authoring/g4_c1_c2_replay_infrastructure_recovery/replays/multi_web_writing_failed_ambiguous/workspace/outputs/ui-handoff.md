# Candidate replay review

**Target screen:** A maintainer’s candidate replay evidence review screen. Place three labeled evidence rows below the screen title; use the empty state when no evidence is available.

**Primary user action:** Review replay evidence to check whether the candidate plugin was used, conflicting plugin paths were read, and cleanup restored the original plugin state.

**UI labels:**

- Candidate plugin used
- Conflicting plugin paths read
- Original plugin state restored

**Empty state:** No replay evidence yet. When evidence is available, review the plugin, path, and cleanup checks here.
