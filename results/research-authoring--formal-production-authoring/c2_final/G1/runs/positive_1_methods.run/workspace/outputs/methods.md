# Methods

## Model comparison and data partitioning

We compared a compact temporal model with a non-temporal baseline using a subject-disjoint data split, with no subjects shared across partitions. The comparison was an exploratory research evaluation and did not constitute clinical validation.

## Performance evaluation and statistical analysis

We evaluated model performance using macro-F1. We used a paired bootstrap procedure to estimate an interval for the difference in macro-F1 between the temporal model and the non-temporal baseline.
