# 研究进展报告：时序模型与非时序基线的初步比较

近期完成了紧凑型时序模型与非时序基线的对照实验。在受试者互不重叠的数据划分下，时序模型取得了更高的宏平均 F1（macro-F1）。这一结果为继续验证时序建模的价值提供了初步依据；增益能否稳定复现、是否来自时序信息本身，仍需进一步确认。当前证据属于初步研究结果，不构成临床验证。

本次比较关注的问题是：在受试者隔离的评估条件下，时序模型是否比非时序基线表现更好。实验笔记记录采用了干净的、受试者互不重叠的数据划分，并通过配对 bootstrap（自助重采样）估计两种方法的指标差值区间。

| 比较项 | 结果 |
| --- | ---: |
| 紧凑型时序模型 macro-F1 | 0.714 |
| 非时序基线 macro-F1 | 0.671 |
| 差值（时序模型 − 基线） | +0.043 |
| 差值的配对 bootstrap 区间 | [0.018, 0.071] |

macro-F1 越高表示该指标下的表现越好。差值由两项已记录的指标相减得到；bootstrap 区间沿用实验笔记，笔记未注明置信水平。

当前比较的点估计与区间均指向时序模型表现更好。不过，笔记尚未提供具体任务、数据集、样本量、模型结构、训练设置、随机种子及重采样单位等信息，因此还不能判断两种方法在模型容量和训练预算上是否充分可比，也不能据此断定性能提升由时序信息单独带来。现有材料同样不足以判断该增益在重复实验或其他数据中的稳定性。

后续建议优先确认增益能否复现。先补齐本次比较的实验设置和 bootstrap 定义，再在明确、可比的条件下开展重复实验，观察差值方向及波动范围。若增益能够复现，再考虑通过控制其他条件的时序消融实验，检验时序信息对结果的贡献。以上为建议开展的工作，尚无相应结果。
