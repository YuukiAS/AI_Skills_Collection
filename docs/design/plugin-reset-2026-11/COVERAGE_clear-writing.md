## 5. 边界条目

以下条目同时涉及“该出现什么”和“怎么表达”。只标交叉点，不替 GPT Pro 划新架构；内容取舍仍须服从读者任务和领域事实。

| 条目行号 | 为什么两边都沾 |
| --- | --- |
| 8–29、32–53 | 要先选出读者缺的连接与动作，再把它写成具体对象和因果链，不能只换术语。 |
| 56–91、93–120 | 要挑出影响裁决的差异及有关交付问题，再把综合结果写成读者能理解和行动的说明。 |
| 124–156、159–186 | 要删重复和无关排除项，同时避免压成术语串，正面说清动作与理由。 |

| 217–245、566–582 | 内部证据是否进正文是取舍，留下的证据怎样服务结论是表达；加载记录不能代替两步的效果。 |

| 302–328、331–356 | 要选会改变判断的证据与限制，再用合乎已有证据的措辞说清推荐，不能越权抹掉未知。 |
