# 在本机跑一批回归

把本工具目录、批次文件和案例放到 Mac 或 Windows 本机，在 **Codex 桌面应用**中打开这个本地目录。装好 Python 3.10 或更新版本（Mac 用 `python3`，Windows 用 `py -3`），用 Edge 登录待测 ChatGPT，准备好案例指定的模型、插件和附件。无需浏览器扩展或调试端口。

首次在 Codex 里说：

> 先读 tools/regression-runner/SKILL.md，跑回归 tools/regression-runner/examples/reasoned-decision.batch。

以后在已加载该 skill 的会话说“跑回归 <批次文件>”即可。上面的迁移批次目前有题面缺口，会列出缺什么，不会自行编题；填入获准的完整案例后再运行。无需全局安装 skill，也不要在集群远程目录里操作本机剪贴板。

每轮弹窗出现后，只做三个动作：

1. 按弹窗选好对话、模型、插件和附件，把剪贴板提示词粘贴发送。
2. 等回答全部完成，点 ChatGPT 的“复制”按钮。
3. 在 Codex 弹窗里点 `好了`（不用打字）；点 `跳过` 跳过余下本案例，点 `停` 保留断点。

结果在当前工作目录的 `runs/<批次名>/RESULTS.md`，原文和逐条判定在各案例子目录。停止后，用同一目录、同一批次继续；不要改旧输入，重测请换批次文件名。

剪贴板为空或还是题面时，Codex 会再提醒一次复制；仍失败就停在原轮次。首次若系统或 Codex 询问目录写入或剪贴板命令权限，按实际提示授权。没有可用提问工具或弹窗未收到明确答复时不会继续采集；本机排除问题后再续跑。
