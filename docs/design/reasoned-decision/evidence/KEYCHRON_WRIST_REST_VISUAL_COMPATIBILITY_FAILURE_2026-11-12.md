# Keychron 掌托选型：视觉证据缺失导致的决策漂移

Status: REAL_USE_EVIDENCE
Date: 2026-11-12
Scope: Reasoned Decision visual-compatibility regression

## 1. 真实问题

用户需要为一把实测前沿宽约 360 mm、前沿高约 18 mm 的直板键盘选择长期使用掌托。此前连续线程主要依赖规格表中的长度、高度、布局标签、SKU 和重量，在 K14、Q8/V8、Q3/V3、K8 等候选之间多次改口。

## 2. 用户补充的关键视觉证据

用户上传两张商品图：

- K8/C1 胡桃木掌托（图中标 PR3）：约 358 mm 宽，正面轮廓为直条矩形；
- Q8/V8 胡桃木掌托（图中标 PR20）：同属约 358 mm 宽档，但掌托前缘/上缘明显按 Alice 键盘轮廓做成弧形/凹形。

这两张图不能直接证明对应硅胶 SKU 的具体形状，因为材质和 SKU 不同；但它们直接证明一个此前被忽略的判断前提：

> 相同或近似的外接长宽高，不足以推出实体轮廓相同。对于几何适配问题，产品的平面轮廓、前缘曲线、斜面、开槽、接口位置等视觉属性可能直接决定兼容性。

## 3. 当前公开市场与官方证据

京东当前索引把以下硅胶款列为同一商品下的独立选项：

- Q8M / V8M / Q8P 硅胶掌托 黑色；
- K8Max / K8Pro 硅胶掌托 黑色与灰色。

京东公开索引可见 Q8 选项对应 item `10096048582601`；K8 黑色选项对应 item `10096048582591`。这说明至少在销售层面它们是两个独立变体，而不是同一个选项的别名。

Keychron 官方当前规格：

- PR45 / PR66：358 × 79.5 × 18 mm，普通 80%，300 g，包含 K8 Max / K8 HE / C1 Pro 8K 等；
- PR57：358 × 79.5 × 18 mm，Alice 65%，265 g，包含 Q8 Max / Q8 Pro / V8 Max 等。

官方 PR57 变体页在选择 `Black / Alice 65% / 358mm` 后仍复用通用硅胶宣传图；这些通用图里出现的是直条掌托，但页面没有证明该图就是 PR57 的实际 SKU 轮廓。因此，不能把“页面在 PR57 选中状态下仍显示直条宣传图”当成 PR57 实物为直条的证据。

淘宝/天猫的公开搜索索引能检出 Q8/Alice 异形掌托及 Keychron 相关商品，但当前工具没有取得可可靠对应到 Keychron PR57 / PR45 硅胶 SKU 的淘宝/天猫实物图。此处必须保持未知，不得用搜索缩略图、通用宣传图或相邻材质版本代替。

## 4. 归因

本案例新增的根因不是“规格没查够”，而是 **Physical Compatibility 被错误降维成 Scalar Spec Matching**：

1. 只比较长、宽、高，遗漏了轮廓形状这个一等变量；
2. 把 SKU 标签和重量当代理变量，却没有直接检查最容易裁决的商品图；
3. 看到“同尺寸”就一度推断“基本同一个东西”，又看到“重量不同”就反向推断“实体适配一定不同”，两边都缺少直接几何证据；
4. 官方商品页使用通用宣传图时，没有识别“variant-selected page ≠ variant-specific image”；
5. 京东/淘宝属于真实购买渠道，用户最终拿到的是卖家当前具体选项，应该优先核对当前销售变体的图、标题、规格和 SKU，而不是只依赖全球官网抽象规格表；
6. 工具拿不到关键图片时，本应明确说“缺这张图会改变结论，请用户补图”，而不是继续用文字元数据填补视觉缺口。

## 5. 应形成的通用规则

对于掌托、保护壳、支架、家具、线材接口、机械配件、服装版型等几何/物理兼容任务：

- 先列出会改变适配的物理变量：尺寸、平面轮廓、曲率、斜面、接口、孔位、支撑面、活动空间；
- 数值规格只能证明 bounding box 或标称参数，不能自动证明轮廓兼容；
- 当“形状”可能改变排序时，Variant-Specific Visual Evidence 必须进入 Recommendation Gate；
- 优先检查用户实际购买渠道（京东、淘宝/天猫等）的当前具体选项图，再用官方页交叉核对；
- 通用宣传图、同系列图库、相邻材质版本、默认 variant 图都不能冒充当前 SKU 的实物图；
- 如果工具无法取得会改变结论的具体 SKU 图，必须显式保持未知并向用户索要截图；不能为了不中断回答而推断；
- 图片证据与文字规格冲突时，先确认图片对应的 SKU/材质/版本，再决定谁有权威性；
- 一张能直接裁决实体轮廓的图片，信息价值可能高于多轮围绕标签、重量和系列名的文字搜索。

## 6. 回归要求

Replay 该案例时：

PASS：
- 在看到 K8 直条木托与 Q8 Alice 弧形木托后，立刻识别“形状”是未核实的一等决策变量；
- 不再把 PR45 与 PR57 的相同 358 × 79.5 × 18 mm 直接解释成形状相同；
- 也不把 300 g vs 265 g 直接解释成哪个更适配；
- 检索京东/淘宝当前具体硅胶 SKU 图；
- 若仍拿不到 PR45/PR57 的 variant-specific 硅胶图，向用户索要对应商品选项截图，并在此之前保持条件性判断。

FAIL：
- 继续只比较毫米数和重量；
- 因 “Alice” 标签直接判不兼容；
- 因相同尺寸直接判同一实体；
- 把 PR57 页面上的通用直条宣传图当成 PR57 实物图；
- 图片缺失时继续生成新的“最终推荐”。
