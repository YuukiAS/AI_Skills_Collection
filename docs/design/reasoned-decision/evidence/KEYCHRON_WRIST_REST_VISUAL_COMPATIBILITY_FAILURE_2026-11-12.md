# Keychron 掌托选型：错误问题表示与证据模态错配导致的决策漂移

Status: REAL_USE_EVIDENCE
Date: 2026-11-12
Scope: Reasoned Decision representation / evidence-modality regression

## 1. 事件概述

用户需要为一把实测前沿宽约 360 mm、前沿高约 18 mm 的直板键盘选择长期使用掌托。连续两个线程先后在 K14、Q8/V8、Q3/V3、K8 等候选之间反复改口。表面上看，改口围绕 329/337/358/365 mm、18 mm、Alice 标签、SKU、300 g/265 g 展开；真正的问题不是这些资料查错，而是 Agent 从一开始就用错了问题表示。

用户真正要解决的是：

> 当前具体掌托的实体几何、支撑面和材料，能否与当前键盘前缘形成合适的长期使用关系。

Agent 实际解决成了：

> 哪个候选的标量规格和类别标签最接近当前键盘。

后者只是前者的一个不完整代理。

## 2. 为什么两张图能一眼暴露问题

用户上传两张商品图：

- K8/C1 胡桃木掌托：约 358 mm 宽，整体为直条矩形；
- Q8/V8 胡桃木掌托：同属约 358 mm 宽档，但前缘/上缘明显按 Alice 键盘轮廓弯曲。

这两张图本身不是当前待买的硅胶 PR45/PR57，因此不能直接证明硅胶 SKU 的形状。但它们证明了一件此前整个决策链都没有建模的事实：

> 相同或近似的长×宽×高，只描述外接尺寸，不描述实体轮廓；而轮廓本身可能直接决定物理兼容性。

用户“一眼看出来”的本质不是视觉直觉更强，而是图片观测到了真正的决策变量；此前的文字规格没有。

## 3. 根因：不是搜索不足，而是 Representation + Modality Failure

### 3.1 Problem Representation Failure

形成候选前，没有先定义“哪些属性在因果上决定适配”。模型默认把最容易检索的字段——长度、高度、布局标签、SKU、重量——当成了完整状态描述。

### 3.2 Evidence Modality Mismatch

待判断属性是二维/三维几何，证据却主要来自文本规格。文本资料再多，也不能补回未观测的轮廓、曲率、斜面和支撑面。

### 3.3 Proxy Escalation

缺少直接几何证据后，模型连续用代理变量填空：

- Alice 标签代理形状；
- 重量差异代理结构差异；
- 官方兼容列表代理实际适配；
- 同样 358 mm 又被反向代理成“基本同一个东西”。

这些代理可能相关，但都不是目标属性的直接观测，因此很容易互相推翻。

### 3.4 Search Objective Failure

搜索目标被错误设成“继续了解候选”，而不是“寻找最能裁决当前未知的证据”。如果决定性未知是轮廓，那么一张对应正确 SKU 的实物图，比多轮标签、重量和论坛搜索更有信息价值。

### 3.5 Missing-Modality Escalation Failure

当工具拿不到关键 SKU 图片时，Agent 没有把“视觉模态缺失”识别成证据边界，反而继续用可获得的文字信息提高结论强度。正确动作应是保持未知，并向用户索取最小必要证据。

### 3.6 Variant Provenance Failure

即使页面切到了某个 variant，也不能默认页面上的图片就是该 variant 的实物图。官方页面可能复用通用宣传图；相邻材质版本也不能直接外推。

## 4. 当前市场/官方信息只支持到哪里

京东当前把以下硅胶款作为独立销售变体：

- Q8M / V8M / Q8P 硅胶掌托；
- K8Max / K8Pro 硅胶掌托。

Keychron 官方当前规格：

- PR45 / PR66：358 × 79.5 × 18 mm，普通 80%，300 g；
- PR57：358 × 79.5 × 18 mm，Alice 65%，265 g。

这些信息能证明它们是不同 SKU，并且外接尺寸相同；不能单独证明它们的硅胶实体轮廓相同或不同。

官方 PR57 页面在选择 Alice 65% / 358mm 后仍可能复用通用硅胶宣传图，因此该图不能自动升级成 variant-specific visual evidence。

当前工具未取得可可靠绑定到 PR45/PR57 的京东/淘宝硅胶实物图，所以硅胶轮廓必须保持未决。

## 5. 应抽象出的 Reasoned Decision 规则

Reasoned Decision 不应只规定“多查资料”，而应规定“先选对证据”。

### 决策变量优先

先列出真正决定成功标准的变量，再搜索：

- 几何/轮廓；
- 接口/孔位；
- 支撑面；
- 材料；
- 运行行为；
- 状态；
- 性能；
- 视觉结果等。

### 证据模态匹配

不同变量需要不同直接证据：

- 几何/外形 → variant-specific 图片、CAD、尺寸图、实测；
- 运行行为 → 日志、trace、真实测试；
- 代码行为 → 源码、测试；
- UI 状态 → 截图/录屏；
- 音频问题 → 录音/频谱；
- 网络路径 → 抓包、连接状态。

### 直接证据优先于代理

有低成本直接证据时，不得优先用类别标签、重量、名称、兼容列表、论坛描述等代理裁决。

### 缺模态时降级，不得脑补

关键变量未被当前模态观测时，继续搜索同一模态不得提高结论强度。必须切换证据模态，或向用户索取最小必要证据。

### 证据来源必须绑定具体对象

图片、benchmark、日志、测试都必须确认属于当前具体 SKU/版本/对象。通用素材与相邻型号只能做旁证。

### 信息价值优先

搜索策略应追求“最短裁决证据”，而不是“更多资料”。一张能直接裁决轮廓的实物图，其信息价值可以高于十条间接文字资料。

## 6. Replay 回归

PASS：

- 先识别“实体轮廓”是未观测的高影响变量；
- 发现当前文本规格不足以裁决；
- 主动切换到具体 SKU 图片/CAD/实测；
- 图片拿不到时请求用户提供最小必要截图；
- 在此之前只给条件性判断。

FAIL：

- 继续只比较毫米数、重量和标签；
- 因 Alice 标签直接判不兼容；
- 因相同尺寸直接判同一实体；
- 把通用宣传图当具体 variant 实物图；
- 在关键视觉证据缺失时继续宣布“最终推荐”。

## 7. 这个案例真正应该留下什么

这不是“掌托要看图”的特殊规则。

它要求 Reasoned Decision 学会：

> 先判断什么属性真正决定结论，再选择能够直接观测这种属性的证据模态。若当前证据模态看不到关键变量，就停止推断并切换模态，而不是在错误的信息空间里继续搜索到更高置信度。


## 8. 最终收尾：证据边界已经正确，却在“最后确认”时再次把局部原则升级成总排名

在视觉证据问题被识别后，Agent 一度给出了正确的更高层判断：

> 人体工学首先看高度、坡度、轮廓和中立腕姿；现有证据不能证明“硅胶长期办公一定优于做工良好的木托”。

这个结论与当前证据边界一致。但用户随后再次要求“最后确认，胡桃木还是硅胶”时，Agent 又把 OSHA/CCOHS 关于“较软、圆润、减少局部接触压力”的局部建议升级为：

> 因此硅胶比硬木更稳妥。

这与上一轮明确陈述直接冲突，而且没有新的 Decision Delta。用户指出矛盾后，Agent 才撤回该推导，并恢复为“材质不是第一决定变量；在几何适配成立后，结合耐久、审美、价格、长期稳定和社区经验做综合选择”。

这暴露出另一个需要独立防护的失败类型：

### Conclusion Strength Drift

模型并不是不知道证据边界，而是在用户要求“更明确”时，为了提供更确定的语气，把一个局部证据维度提升成了全局排序依据。

### Local Principle → Global Ranking Fallacy

“较软可减少局部接触压力”只能说明软材质在某个风险维度可能有优势；除非证据证明该维度对当前成功标准具有支配性，否则不能推出“硅胶整体优于木托”。

### Cross-turn Contradiction

如果上一轮已经明确写出“没有证据证明硅胶整体优于木托”，下一轮要写“硅胶更稳妥”，必须先有新证据、约束变化或逻辑纠错。单纯因为用户再次追问，不构成合法改判。

## 9. 真实终局

用户最终购买：

- 胡桃木；
- 直条圆边；
- 360 × 80 × 19 mm。

该尺寸与用户实测键盘前沿约 360 mm 宽、18 mm 高基本匹配。

最终选择胡桃木的合理依据是多维综合权衡：

- 几何尺寸匹配；
- 直条轮廓；
- 长期稳定、不塌陷；
- 表面移动顺畅；
- 耐久；
- 审美；
- 价格；
- 机械键盘社区长期使用经验。

该选择不能被表述成“木头已被人体工学研究证明优于硅胶”；同样，也不能把硅胶在局部缓冲压力上的优势表述成“因此硅胶整体更适合长期办公”。

用户已经完成购买并明确结束 thread，因此该选择问题应进入：

- COMPLETED_ACTIONS：已购买 360×80×19 mm 圆边胡桃木掌托；
- CLOSED_QUESTIONS：胡桃木 vs 硅胶；
- DO_NOT_REVIVE：没有真实使用失败、尺寸不符或用户主动重开时，不得再次启动材质总排名。

## 10. 新增回归要求

PASS：

- 能保持“材质不是第一决定变量”的证据边界；
- 用户要求最终选择时给综合权衡，而不是制造单一科学定理；
- 发现当前结论与上一轮明确证据边界冲突时，要求合法 Decision Delta；
- 用户购买后关闭问题，不再继续扩候选。

FAIL：

- 因用户要求更明确就提高结论强度；
- 把局部人体工学原则直接升级成总排名；
- 同一证据集下相邻两轮输出互相矛盾；
- 用户完成购买后仍无证据复活“换不换另一种材质”。
