## 0. 验收原则与归因

要验证的不是“说人话规则写进了几个文件”，而是普通用户**不额外点名 Clear Writing**时，首次完整回答、已生成报告、界面文字和实际幻灯片是否获得可重复、语义保真的改善。评估必须观察完整产物，避免固定禁词、英文字符比例、段落数量、日志词计数、调用自述、存在性测试或只选最佳一次作为独立通过证据。

一份回答可以在目标中文中合法保留 `JWT`、精确字段、论文正式名称、路径、命令和模型名；真正失败是普通工程解释仍被不必要英文与来源流程标签搭起骨架，或为了润色而误改事实。一个正常英文论文也不能因“英文多”被错误拦截。表达质量与语义保真必须分别检查；必要机器输出和准确引用不可随意改写。

已知回归先做低成本检查；最后候选、材料、语言合同、分组、次数和评审准则冻结后再执行未见完整任务。最终不可用不同提交或不同插件包拼凑各自的通过记录。Reviewer 必须直接阅读全文或真实渲染结果，并能访问精确必要来源；没有实际源文时不能证明无遗漏/不变更。

## 1. 能力矩阵

| 编号 | 证明的独立用户能力 | 正常入口与必要证据 | 明确失败与应保护的已有能力 |
|---|---|---|---|
| G0：同源双端可安装 | ChatGPT 与 Codex 拿到同一权威技能源构建的正确版本 | 完整源身份、版本、生成/包装清单、Plugin Creator 个人 Web 安装与新会话、Codex 市场安装与新任务；各自可见身份 | 只在仓库有文件、只本地加载、错误缓存、Web/Codex 源不一致、冒称另一个插件身份 |
| G1：无需 `@` 的可用性与真实增量 | 普通使用时不需用户每次提醒，候选效果不等于短提示词自身作用 | 新 ChatGPT 会话、有/无 Project 与各自有效阅读规范；冻结同类完整任务 A–D 配对对照；Codex 普通任务从正式安装入口运行 | 只有显式 `@` 才可用；B 与 C 无实质差异却宣称插件自动发挥增量；只相信调用自报；负例抢错误技能 |
| G2：可直接阅读的自然表达 | 首屏回答先给结论，技术解释不受来源英文、流程标签和机械换行支配 | 私有案例的公开安全等价材料、英文日志/论文/仓库/技术规划输入后完整首答；人工逐项审查中文关系、信息顺序、段落组织和必要英文角色 | 非必要英文成为叙事骨架、裸日志替代判断、单字段/一句一段、堆叠重复状态；为短而删掉必要前提 |
| G3：语义保真与机器内容分层 | 清晰表达不能改变科研/工程/权限及协议原意 | 命题级来源→产物检查：数值、公式、否定、条件、比较、结论强度、时间/完成状态、授权/安全、引用、精确标识；纯代码/JSON/YAML/原始日志/逐字要求与混合任务 | 任意受保护项漂移、删限制、来源作者计划变模型行动、代码字段被翻译、机器纯输出被添文字 |
| G4：专业文档完整质量 | 不退化为“普通对话润色正确，正式产物读起来仍像机器生成” | 已有文本轻润色、中文科研技术重型重写、英文科研文字、普通报告等真实完整材料；必要 PDF/Markdown 渲染与全文质量审查；保留旧长文已知回归 | 重度主链退化、表格/公式/合法代码被删除、引用失真、整篇仍是执行备忘录或拼接报告；禁止强行改 Research Authoring |
| G5：领域交接与更名兼容 | Frontend Design、Presentations、软件/统计说明能够正确消费相应表达能力 | 正常前端任务→冻结产品含义→界面文字→真实页面；正常演示任务→冻结页内容→语言表达→实际渲染；Codex 普通技术说明；运行记录显示同一候选确被消费；真实旧消费者正反回归 | 前端按钮被改坏真实后果、幻灯片变密或改科学结论、改名断路、只有协调文档而无调用证据、UI 写作抢普通问答 |
| G6：语言模式、多轮与不应改变 | 有 Project / 无 Project、简繁英双语和一轮覆盖均不污染后续 | 新会话→普通回答→连续跟进→大量英文源→纯机器轮次→当前消息英文覆盖→恢复默认；英文项目与香港繁体界面等对照 | 临时语言永久化、英文 Project 被强制中文化、机器轮次导致长期绕过、简单任务被过度扩写 |
| G7：冻结最终候选的独立质量证明 | 不是只对已见案例或原作者自检有效 | 冻结最终包和真实安装身份、事先固定任务族及最大次数、实现后揭示公开安全未见样本、完整真实产物；独立 Reviewer 同时检查 G1–G6 适用边界 | 冻结后修改候选/评分器、换题追加赢家、只用局部断句或合成脚本通过、不同 candidate 的记录拼接、未见样本再次调参 |

G0 是双端的分发能力；G1 是静默进入用户任务的行为；G2 是读者表达质量；G3 是改写不会伤及受保护语义；G4 是完整专业文档质量；G5 是领域使用与改名兼容；G6 是长期/跨语言模式；G7 是无调优污染的完整泛化。不得为增加 Gate 数目再按词类/语言/案例拆同义门槛。

## 2. 关键对照的精确含义

**ChatGPT Web 有 Project：**

- A：冻结的相同 Project 语言合同；候选 Clear Writing 已安装；不加专门激活短桥。
- B：相同合同；候选已安装；只增加一条短激活桥。
- C：相同合同、相同短桥；无新候选或使用不含新能力的上版。
- D：明确 `@Clear Writing`，仅诊断包/技能可被调用，不属于正常入口。

**ChatGPT Web 无 Project：** 全局个性化合同固定，比较“候选已安装”与“无候选/旧版”，用户任务本身不包含技能名或“请说中文”等针对性激活词；要求第一条完整回答符合当前语言偏好。项目内外的原始差异必须分开报告。

B 相对 C 没有可靠改善时，不给新增插件的自动阅读能力通过；若 A 也稳定成功，可以取消强制短桥。若平台根本不显示内部技能调用，最多报告“效果与候选安装存在可观察相关性”，不能说已证实每轮技能调用或内部执行顺序。

**Codex：** 提问者不写技能名，正式安装环境中的用户任务进入相应领域插件；以来源/中间语义/完整产物和运行证据判断 Clear Writing 是否在正确阶段真实影响结果。要同时有不应变化的负例：纯数据后端任务不触发 `interface-writing`，纯脚本/日志不被改写，普通短任务不进入重度科研重写。

## 3. 预定任务族（由 Critic 决定最终最小覆盖量）

必须覆盖的失败族，而非固定样本数：
1. ChatGPT 普通科研/统计解释，含必要公式、比较条件和未证实断言；
2. ChatGPT 技术/服务器排障，含长英文日志、主机/路径/命令与无关内部流程标签；
3. ChatGPT 正常架构决策类回答，避免大段缩写和机械列表，同时保留安全授权；
4. 普通短问答、英文明确要求、香港繁体地区文案、双语边界、纯 JSON/代码/原始日志、混合机器与解释；
5. Codex 中文文档与较长已有科研技术材料的正常写作/重写；
6. 英文科研文字，尤其来源/结论/未来工作主体及时态保真；
7. Frontend Design 应用界面文字的真实渲染与用户后果；
8. Presentations 文案及完整幻灯片的真实渲染、页面层级和科学结论；
9. Codex 面向用户的普通软件任务总结、报告与统计结果说明；
10. 技能命名迁移正例、近似边界反例、旧配置/个人安装恢复与同源生成的一致性。

已曝光 C5–C11、051–055 或其它用户明确指出的质量问题只用于开发回归，不进入同一轮最终未见样本；用户私有全文不进入公开仓库。可用自行设计且不含隐私的内容进行公开审查，真实敏感产物另通过事先授权的接收途径供 Reviewer 实读。

## 4. 执行时序与停止条件

1. 设计 Critic 先独立评审本矩阵与提案，检查过重/过简、角色错误、名字误导、路由可行性、两端包装、候选增量及实际用户成本；没有 PASS 不创建 Executor。
2. 经批准的开发先用既有回归和不应变化样本，不在很晚阶段才第一次让人完整阅读一个候选；真实 UI、整份文档和整套幻灯片必须在最终冻结前经过定性查看。
3. 关键双端分发与 G1 正常入口如果技术上不成立，应停止自动最终审校能力声明，返回 Planner 评估“持久基本规范 + 已有场景技能”或明确调用的更简版本；不能用 Codex 代替 Web 或用 `@` 代替无 `@`。
4. G2 自然语言质量失败或 G3 语义漂移都阻断；G5 改名断开实际 Frontend/Presentations 也阻断，不允许只让新技能本身通过；研究写作插件未参与本轮，不用它的未验证状态虚构通过或失败。
5. 最终候选及评审标准冻结后，再按风险选定且一次性公开安全未见批次；确有产品失败即本候选失败，样本变成已知回归，不能通过加例或挑赢家洗白。
6. 独立 Reviewer 直接看到完整原始来源、最终回答/文件与必要渲染，分别报告自然表达、保真、机器内容、自动进入、迁移兼容及表面差异。Critic 对真正重大歧义裁定，不由 Planner 假装独立审查。
7. 只有所有发布关键 Gate 由同一个正式候选直接通过，并由用户按授权边界接受后，才能变更生产插件、个人安装、仓库 main 与必要消费者。部分通过必须按表面报告，不得称“今后 ChatGPT 所有回答必定强制执行”。

## 5. 证据与记录最小集

保留源提交、候选技能与生成包身份、实际安装结果、跨条件任务/初始指令、完整回答或真实产物、独立人工/外部审查、旧功能回归、命名引用迁移差异和回退方式。数值/关键词统计只供诊断。对于每项真正需要完整渲染的交付物，Reviewer 应取得能直接查看的 PNG/PDF/网页或原生实际结果；无法访问完整产物就不能宣称对应能力通过。

不建立新状态数据库、额外浏览器扩展、发送前钩子、独立模型服务、自动重试链、跨插件通用调度器、机械禁词评分器或长期 watcher。
