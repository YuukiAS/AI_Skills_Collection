# 流程图第五版规格：细节修整

在第四版（`ASSURANCE_PROCESS_V4_20261110.d2` 与渲染脚本）基础上修改；内容以 `ASSURANCE_PROCESS_V0_1_20261110.md` 为准，第三、四版规格的视觉规则继续有效。设计已定，不要自行设计；做不到的地方停下说明。

## 内容修改

1. **档次名称：** 规划端的两档写全为“规划端·专业”“规划端·普通”；执行端保持“执行端·专业”“执行端·普通”。卡片表头与图例都改。
2. **X4、X5 区分清楚：**
   - X4 表头“X4 专项检查 · 执行端·专业（按条件）”，正文“用现有插件或工具按既定准则逐项检查：版式、文案规范、视觉回归、领域规则；只交证据”。
   - X5 表头“X5 独立裁判 · 规划端·专业（按条件）”，正文“不看实现过程，判断最终产物是否真正满足冻结的验收语义：结论、推导、图表是否成立；只交证据”。

## 布局修改

3. **箭头不出框：** 同一容器内部的连线（包括红色补缺口、大改、返修线）必须完整留在该容器内，不得有任何一段越出容器边框。只有跨容器的线（退回请求、验收器提案、冻结合同进出）可以离开容器。例如“全部通过？→ D1 汇总”的补缺口线要在左容器内侧绕行。
4. **X4 与 X5 并排：** 放在同一行，X4 在左、X5 在右，中间留出通道。“是；按条件验收后”的主流程箭头从“校准与验收全部通过？”直下，穿过 X4 与 X5 之间的通道，到“X1 签发？”。X4、X5 各从上方菱形接入（虚线），证据点线各自回 X1。
5. **对齐与笔直：**
   - 上下相邻、宽度相同的卡片中心对齐，连线垂直笔直，从上卡片底边中点到下卡片顶边中点（例如 X1→X2）。
   - 消除所有不必要的折弯和小错位：每条线只在确实需要绕行时折弯，折弯处用统一圆角。
   - “X1 签发？”菱形左侧入线不得有莫名的小拐弯；所有接入菱形的线从菱形顶点接入。
6. **标签贴线：** “是”“否”“按条件”等短标签离所属线不超过 12px，放在线的同一侧，不悬空。
7. 保持第四版已经做到的：零交叉；退回请求从 D1 上侧接入，验收器提案从 D1 右侧接入；冻结合同在回流线下方。
