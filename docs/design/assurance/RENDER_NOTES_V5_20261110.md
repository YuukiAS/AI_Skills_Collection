## 实际运行与重建

实际使用 D2 0.9.0＋ELK 取得布局，沿用第四版 SVG 后处理方式绘制卡片和走线，再由 Playwright 1.56.0 调用 Chromium 143.0.7499.192 直接打开 SVG，等待字体加载后，以 2 倍分辨率截图。SVG 为 3389 × 1788，PNG 为 6778 × 3576。没有使用 librsvg，没有拼接或转换其他渲染器的图像。

SVG 嵌入 Noto Sans SC 的 400、600 两套字体，浏览器确认两者均已加载，中文、英文和数字使用同一字体。

在本工作树根目录运行：

```bash
PYTHONDONTWRITEBYTECODE=1 python docs/design/assurance/render_assurance_V5_20261110.py
```

依赖复用工作树 `.cache/assurance-diagram/` 中的 D2、字体与 Playwright；本版浏览器配置、中间文件和自查结果位于被忽略的 `v5/` 子目录。
