# 流程图第三版规格：视觉重做

依据 `ASSURANCE_PROCESS_DRAFT_V2_20261109.md`，流程内容与第二版相同，本版只改视觉与节点组织。设计已定，执行者按规格实现，不自行设计；做不到的地方停下说明。

用户对第二版的意见：字体效果差；标签和线重叠（例如“否：补缺口”）；块内文字乱；出现没有角色的方框（例如“运行冻结验收器”）；箭头颜色与粗细不讲究。

## 1. 节点：一律是“角色卡片”

**每个方框都必须是一个具体角色。** 不再出现没有角色的方框。决定一律用菱形，产物一律用文档形状。

卡片结构，上下两栏，中间一条分隔线：

- **上栏（表头）：** 编号、角色名、档次，例如“D1 设计负责人 · 高”。按档次填色（见第 4 节），字重 600，16px。
- **分隔线：** 1px。
- **下栏（正文）：** 白底，写这个角色负责什么，最多两行，字重 400，13px，深灰 #374151。
- **不写**“新开”“沿用”之类的线程规则，也不写担任的模型名（模型名只在图例里出现一次）。

卡片样式：圆角 10px；外框 1px #D1D5DB；无阴影；宽度按内容统一为几档，同一列的卡片等宽。可选角色的外框改为 1.5px 虚线。

## 3. 连线

| 用途 | 颜色 | 粗细 | 线型 |
|---|---|---|---|
| 正常流程（必跑） | #4B5563 | 2px | 实线 |
| 正常流程（可选） | #4B5563 | 2px | 虚线 6 4 |
| 退回或补缺口 | #DC2626 | 3px | 实线 |
| 验收器提案（只有建议权） | #EA580C | 2px | 实线 |
| 修订后的新版本 | #7C3AED | 2.5px | 实线 |
| 交回证据，不转移负责权 | #9CA3AF | 1.5px | 点线 2 4 |

- 箭头头部统一为实心三角，大小与线宽成比例，同类连线一致。
- 拐角用圆角正交折线；平行的线之间至少留 16px。
- **所有连线标签放在白底小标签里**（圆角 6px，内边距 4px 8px，字号 12px，颜色与连线相同），**任何线都不得穿过标签或卡片文字**，标签离最近的线至少 8px。
- 两条修订线上各挂一个琥珀色小标签“动手前、完成后都告知用户”，样式同上，底色 #FEF3C7、字色 #92400E。
- 退回请求的四类原因写在一个红色描边的说明框里，放在两大容器之间上方，用短线连到退回线，不用悬空的散字。

## 6. 渲染与自查

- 继续用 D2 + ELK 生成布局；若 D2 的标签背景或连线样式做不到上述要求，可以在导出的 SVG 上用脚本后处理（标签白底、线宽、箭头），但不得改变结构。
- **PNG 用 Chromium（Playwright）打开 SVG 截图，2 倍分辨率**，不用 librsvg，以获得正常的字体抗锯齿。
- 输出 `ASSURANCE_PROCESS_V3_20261110.d2`、`.svg`、`.png`，第一、二版文件保留。
- 自查清单，逐项打开 PNG 确认：
  1. 没有任何标签或文字被线穿过；
  2. 每个方框都有角色编号或“用户”；
  3. 卡片上下栏与分隔线清楚；
  4. 同类连线颜色、粗细、箭头一致；
  5. 可选与必跑在线型上一眼分得清；
  6. 100% 缩放下正文清楚可读；
  7. 没有大块空白。
