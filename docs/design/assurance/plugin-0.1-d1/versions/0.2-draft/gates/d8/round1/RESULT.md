## D8 confusion 判准修正

本轮同时确认一个提示词问题：D8 不负责追问实现细节。以后只有在某个歧义会导致不同的角色、决定权、输入、输出、推进条件、失败去向或用户动作时，才记录为 `confusion`。

以下内容本身不构成 D8 confusion：字段名、文件格式、状态枚举、日志结构、内部 ID、具体保存路径、任务书 schema、时间戳或其他低层实现细节。只要当前单位已经足够让读者正确复述“谁在什么条件下做什么、得到什么、失败怎么办”，就不应因为这些细节没有展开而报疑惑。
