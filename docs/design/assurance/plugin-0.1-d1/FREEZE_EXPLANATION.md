## 交付什么

两个插件：**Design Assurance**（设计端）和 **Delivery Assurance**（交付端）。

- 设计端：从需求出发，派独立设计、合并、过四道关卡，得到你批准的冻结设计。
- 交付端：只按冻结设计安排实现和验收，修验收程序时不能偷偷改“什么算完成”，最后由 X1 亲自看最终成品和原始证据后签发。
- 任何时候，你都能从当前状态拿到下一条完整的提示词：发给哪个角色、在哪开线程、写回哪里。

## 怎么用

- **规划端**（D1、X1 和其他规划角色）：在 Claude Code、GPT Work 或 ChatGPT 网页端读同一份规则。规划端角色都在 GPT 上跑，每个角色每轮只转交一次。
- **执行端**：Codex 安装后的两个执行技能 `design-assurance-execute`、`delivery-assurance-execute`，只接负责人明确派发的工作。
- **ChatGPT 网页端**：沿用 thread handoff、thread instruction 已经测通的打包方法，网页端只负责读状态、生成提示词、按派发写回，不声称能跑本地脚本。
