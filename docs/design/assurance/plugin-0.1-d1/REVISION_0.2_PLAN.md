# Assurance 冻结后修订计划（D1，2026/11/15，用户已同意方向）

实现尚未开始，两处修订合成一次大改，形成新的设计草稿（语义版本 0.2）；冻结的 0.1（`versions/0.1/`）保持不动，作为历史。

## 修订一：D1 澄清吸收 Grill Me 的提问方式（不加外部依赖）

来源：`mattpocock/skills` 的 `skills/productivity/grilling/SKILL.md`（MIT，Copyright 2026 Matt Pocock）。原 skill 很短，规则见下；我们只吸收提问方式，不在运行时依赖它，原因：插件运行在 Claude Code、GPT Work、ChatGPT 网页端、Codex 四端，不能假设该 skill 已安装；且它“所有决定都交给用户”与我们的三类分法冲突。

D1 澄清新规则（替换 SPEC 第 6.1 节及 Blueprint 中 D1 澄清节点的对应文字，保留未提及的既有规则，如“回答仍有效才不重复问、新事实推翻前提时说明原因重开”）：
1. **问题三类分法保持不变：**只有用户能定的才问用户；能查到的事实由 D1 自己查或派执行端查，绝不问用户；设计者该定的技术选择由 D1 自己定并写理由。
2. **决策树与轮次（来自 Grill Me）：**把待定事项组织成决策树；每一轮只问“前提已经确定”的那些用户问题（前沿），一轮问完整个前沿；某问题的答案依赖本轮另一问题时，放到下一轮。查事实不阻塞：只有依赖该事实的问题等待，其余照问。
3. **问法（来自 Grill Me）：**每个用户问题编号、给出 D1 的推荐答案和一句理由；措辞使用户回答“是”即接受推荐。
4. **结束条件：**前沿为空、没有静默假设的分支，并经用户确认已达成共同理解，才进入设计。
5. 每个用户回答记为带出处的需求（同现行规则）。
6. 共享资源中附 `NOTICE`，注明吸收自 grilling skill 及其 MIT 许可全文。

## 修订二：冻结审阅改在 Blueprint 中进行，取消单独的冻结说明

原因：冻结说明是对 Blueprint 的转述，D6 第 10–17 轮反复发现转述走样。用户今后在 Blueprint 界面里审阅并批准冻结。

1. **内容放进 Blueprint：**新增一个顶层节点组，id 为 `freeze-review`，名称“冻结审阅”，含 7 个子节点，各自的正文（Blueprint 现有字段，如 terminal 的说明字段）写清对应内容，并引用相关节点 id：
   - `fr-decisions`：用户做过的决定、设计者定的默认做法（标“默认”）、被放弃的方案（并入 `MERGE_DECISIONS.md` 中影响用户的部分）；
   - `fr-asks`：哪些情况会交用户决定或确认；
   - `fr-costs`：增加用户工作量、费用或权限的事；
   - `fr-roles`：各角色何时启用、在哪里运行、谁派发、各负什么责任（角色档次表引用 2.1 节原表，不转述）；
   - `fr-validation`：验收器与回归用例集的说明（数量与分类由界面从 Blueprint 自动统计，正文只写规则与例外）；
   - `fr-downloads`：单项超过 100 MB 的下载或安装（未记录大小的写“未记录”，并保留首次下载前记录大小、超过 100 MB 先问用户的规则）；
   - `fr-nongoals`：不做的事与不保证的事。
2. **批准对象只剩 Blueprint：**用户批准的是 `snapshot_sha256`；删除 `explanation_sha256`、冻结说明文件格式（SPEC 6.4a）及 D6 对冻结说明的四项检查。`freeze.json` 去掉 `explanation_sha256` 字段。D6 像审其他组件一样审 `freeze-review` 节点组（答案是否在 Blueprint 中、是否与其他节点矛盾）。
3. **界面：**Blueprint 应用新增“冻结审阅”视图（单独实现任务），按上述 7 部分顺序展示 `freeze-review` 节点内容，并自动派生：验收器总数与分类计数、回归用例数与按检查条的分组、角色档次表、单项下载大小、当前 `snapshot_sha256` 与 D5–D8 关卡状态；每项可跳转到来源节点。

## 关卡与收口

按修订规则属于大改，在新快照上重跑：D5（机械，全量）、D7（Codex，全量）。D6 覆盖自上次通过以来自身字段有变化的全部节点，按节点自身字段计算，子节点变化不重复归到父节点；本轮为全部 62 个节点。D8 覆盖文字有变化的读者单位，并按既有规则纳入受影响的同一步骤或同一失败路径单位；文字和哈希均未变的单位沿用最近一次真实通过记录。范围以实际差异确定，不限于 freeze-review 组、D1 澄清节点和冻结节点。D6/D8 定向复核只查改动位置及其直接引用；改动之外的新发现记为 non-blocking 留给 0.3，除非与改动直接矛盾。若只发现转述性偏差，D1 按 Blueprint 原文改正后机械核对，不再开无边界的新轮。
