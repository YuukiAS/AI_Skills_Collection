# D8 第 1 轮后的术语补充（D1 定稿）

第 1 轮中有 27 个单位，读者因为代号和术语没有解释而读不懂。改写规则如下：
- 下表中的词，在每个单位第一次出现时，就地换成“解释在前、原词或代号在括号里”的写法；同一单位里再次出现时，只写简称。
- 只改读者看到的六个字段：`title`、`action`、`exampleData`、`expectedResult`、`why`、`onError`。
- 不改含义，不增删步骤。
