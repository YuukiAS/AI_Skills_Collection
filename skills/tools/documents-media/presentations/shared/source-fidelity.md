# Source Fidelity

Every non-trivial deck must preserve evidence boundaries.

- Use `source_anchors` for Markdown headings, PDF pages, figure/table IDs, code output paths, prior slide numbers, or reviewer comments.
- Separate completed results, planned work, hypotheses, and speculation.
- Keep formulas in LaTeX.
- Do not invent claims, citations, result values, or decisions.
- Keep the deck plan alongside the delivered deck.
- For `research-group-meeting`, keep internal Research State fields separate from slide text. They guide planning but must be translated into scientific questions, evidence, failures, uncertainty, experiments, and decisions.
- Build an Evidence Board before slide planning. A claim without evidence must become missing evidence, next experiment, speaker note, backup, or deletion.
- Do not commit downloaded whole-slide reference decks, screenshots, public PDFs, or clinical images unless rights and privacy are explicit. Commit source metadata, URL, page number, page function, visual lesson, what to learn, what not to copy, and rights note instead.
