# 公共保真

所有改写、重组、摘要、内容删减和局部返修都使用本规则。保真保护事实与关系，同时服从用户明确授权的编辑类型。

**FI-01｜先确定编辑类型。** 区分润色、局部修改、结构重组、摘要或内容删减、翻译，以及纯排版或渲染。每种类型只允许相应范围的变化。

**FI-02｜锁定当前权威。** 记录当前来源、最新用户修正、最新接受稿和本轮编辑范围。旧稿可以提供文风参照，事实、版本、状态和最终对象继续服从当前权威材料。

**FI-03｜标记受保护内容。** 保护事实、数字、日期、单位、公式、变量、引用、归因、比较对象、条件、限制、不确定性、负结果、完成状态、权限边界，以及必须逐字匹配的代码、命令、路径、文件名、字段、配置键和正式名称。

**FI-04｜保持拒绝内容退出。** 用户已要求删除的整节、含义、标签或表达记录在 `rejected_content`。后续版本不得通过改标题、换词、移位或恢复旧稿使其重新出现。

**FI-05｜保护关系与位置。** 检查结论与条件、数字与对象、引用与主张、公式与适用实验、限制与所限定内容、状态与动作后果之间的对应。字符串全部存在仍可能发生归属错误。

**FI-06｜局部修改保持范围稳定。** 润色和局部返修保留原有实质内容、已确认结构及范围外文字。相邻区域只有在当前修改造成直接冲突时才联动处理，并在执行证据中说明原因。

**FI-07｜结构重组遵守内容计划。** 获准时可以调整标题、章节顺序、段落组合、表格组织和解释位置。全部实质命题、证据、限定、比较关系、引用归属和结论强度继续保持；Content Selection 的计划决定保留、移层和删除。

**FI-08｜保持模态。** 区分已完成、计划中、条件成立时、尚未验证和推测；保持原主体、时间和证据强度。来源中的未来工作不能写成当前执行动作，初步观察不能写成确定结论。

**FI-09｜按读者任务处理过程信息。** 支持复现或操作的脚本、配置、命令和当前有效入口可以保留在合适位置。分支、提交、CI、评审状态和制作记录只有在交接或审计任务中才进入读者正文。

**FI-10｜完成双重核对。** 先用机械方法核对精确项、哈希、文件和版本，再由 GPT 对照来源检查语义覆盖、归属、限定和可读性。机械通过只证明已检查的机械性质。

**FI-11｜遇到缺失或冲突时返回负责人。** 科学定义、产品状态、引用归属或授权边界无法从当前权威材料确定时，列出最小缺口并交回相应负责人。GPT 不猜补含义，Codex 不作内容裁决。
