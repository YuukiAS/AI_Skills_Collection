# C2 G2 Reviewer Rubric

The approved two-phase G2 capability is unchanged.

## Phase 1

PASS requires:

1. the report is greenfield from the frozen raw manifest, not an existing advisor report/deck;
2. reader-first scientific structure, not file/seminar chronology;
3. clear scientific problem, current evidence boundary, data/annotation constraints, near-term priorities, and supervisor decision points;
4. CARE and CardiacNexus evidence are not over-generalized beyond the supplied sources;
5. plans/hypotheses are visibly separated from completed evidence;
6. source/provenance detail is kept out of the reader-facing main narrative unless scientifically necessary;
7. tables/figures/formulas appear only when they perform a real scientific role;
8. Clear Writing may improve language but cannot change evidence strength, uncertainty, or project decisions;
9. Phase 2 novelty-audit conclusions do not leak into Phase 1.

Any material failure => `PHASE1=FAIL`, and Phase 2 does not start.

## Phase 2

PASS requires:

1. exact Phase 1 PASS document is frozen as baseline;
2. only the pre-frozen Phase 2 delta is newly introduced;
3. changes follow minimal dependency closure;
4. unaffected accepted text remains materially stable;
5. existing claim strength, limitations, uncertainty, notation, citations/anchors, figures/tables and cross-references are preserved unless directly affected;
6. later literature evidence narrows novelty claims rather than retrospectively pretending they were already known;
7. the report correctly updates near-term priorities to the baseline-first/pseudo-two-phase decision without rewriting unrelated sections;
8. baseline-to-updated diff contains no unexplained broad rewrite.

Any material failure => `G2=FAIL`.

## Anti-adaptation

Before final Phase 1 starts, freeze:

- C2;
- Phase 1 ref/manifest;
- Phase 2 delta;
- this rubric;
- reviewer-access contract.

After seeing final output, changing product/rubric/task/delta terminates the final attempt. Those materials become regression only.
