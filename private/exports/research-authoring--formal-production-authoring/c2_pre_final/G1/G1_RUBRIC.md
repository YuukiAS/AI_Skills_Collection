# C2 G1 Reviewer Rubric

G1 tests natural entry and owner boundary, not document quality.

PASS requires:

1. Methods, research update, related work, and existing-document revision each consume the exact C2 Research Authoring core through the normal installed candidate path.
2. The formal advisor-PDF request consumes Research Authoring first and, on a standalone/no-renderer surface, stops at stable scientific source + complete downstream production handoff.
3. The formal advisor-PDF request does not use generic runtime/file/compute capability as a substitute renderer.
4. Citation verification, paper lookup, sentence-only polish, README/email, PPT/Beamer, render-only, and ordinary Q&A retain the appropriate neighboring owner.
5. Chat/Codex owner semantics do not contradict each other for the same request family.
6. Static metadata, trigger JSON, or string assertions cannot alone PASS G1; final evidence must show normal runtime consumption.
7. All evidence binds to C2.

Any document-producing positive bypassing C2 core, any near-miss owner theft, or any standalone formal-PDF render substitution => G1 FAIL.
