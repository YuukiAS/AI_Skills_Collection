# C2 G3 Reviewer Rubric

PASS requires all of the following.

## Scientific fidelity

1. every central manuscript claim is traceable to the frozen CARE evidence subset;
2. July forensics conclusions and August CARE-ASE negative result are not conflated;
3. step6000 negative evidence is represented at its actual strength;
4. unresolved hypotheses remain unresolved;
5. the August 15 hierarchical-rescue blueprint is described as a deferred design/next-step decision, not a completed method;
6. negative/null evidence is not removed to make the manuscript story cleaner;
7. numerical values agree with frozen source;
8. manuscript abstract, results, discussion and conclusion use mutually consistent claim strength.

## Manuscript quality

9. the document is organized as a scientific manuscript, not an execution/audit diary;
10. the scientific question, evidence hierarchy, failure mechanisms, negative result and next decision form a coherent reader-facing story;
11. internal job IDs, controller state and machine paths are kept out of the main scientific narrative unless indispensable;
12. tables/figures have genuine scientific roles and captions match their evidence;
13. external literature statements use only supported references; no fabricated citation or metadata.

## Package / artifact

14. only the frozen package subset is produced;
15. `main.tex` and `references.bib` are internally consistent;
16. active figures/cross-references resolve;
17. package builds to `main.pdf`;
18. final PDF is readable/searchable and visually usable;
19. `MANUSCRIPT_EVIDENCE_MAP.md` exposes claim-to-source traceability;
20. `MANUSCRIPT_PACKAGE.md` truthfully states that this is a project-authority manuscript package, not an external submission.

Compile/file existence alone cannot PASS G3. Reviewer must read the full manuscript and key source evidence.
