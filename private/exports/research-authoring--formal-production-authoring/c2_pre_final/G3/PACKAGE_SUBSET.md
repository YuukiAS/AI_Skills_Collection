# C2 G3 Frozen Manuscript Package Subset

The task must create a real, buildable manuscript package without manufacturing unrelated sidecars.

Required output:

1. `main.tex` — manuscript-ready scientific source;
2. `references.bib` — only external literature references actually cited in the manuscript;
3. `figures/` — only frozen/source-derived figures that perform a real scientific role;
4. `main.pdf` — compiled, readable manuscript artifact;
5. `MANUSCRIPT_EVIDENCE_MAP.md` — claim/section -> frozen source/evidence anchors;
6. `MANUSCRIPT_PACKAGE.md` — source ref, build route, included files, limitations, project-authority statement.

Optional only if the manuscript actually needs them:

- tables split into external files;
- supplementary technical appendix;
- additional figure files.

Explicitly not required:

- cover letter;
- reviewer response;
- author metadata for a real submission;
- reporting checklist unrelated to this technical paper;
- submission manifest claiming an external venue;
- empty supplement/declaration files.

The CARE repo remains read-only. Materialized source and candidate output live only in the AI_Skills C2 private export.
