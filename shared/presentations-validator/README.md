# 通用 deck 验收器

对 PDF 幻灯片做离线验收，生成失败证据和逐页人判清单。PDF 是必需输入；可另给 `.tex` 辅助检查源码。本工具不调用模型，不执行 TeX，也不上传输入。

```sh
python -m pip install -r shared/presentations-validator/requirements.txt
python shared/presentations-validator/validator.py slides.pdf --out validation
python shared/presentations-validator/validator.py slides.pdf --tex slides.tex --profile v19 --out validation
```

每次运行写 `report.md` 和 `report.json`。Markdown 先列总判定和「规则、页、证据」失败表，再列人判内容与机械初筛提示。JSON 包含输入与规则哈希、逐页逐规则覆盖、检测错误及运行时间。输出可能包含输入文字，私有 deck 的报告应保存在公开仓库之外。

命令退出码：`0` 表示没有自动失败，`2` 表示存在自动失败，`3` 表示检测未完成或发生错误。**退出码 `0` 仍可能是 `REVIEW`，不能据此宣布整套 deck 通过。** 只有人判也完成后，调用方才能作最终验收；本版不接收或代签人判结果。

## 检查范围

`rules.yaml` 保留 108 条通用规则，另补 9 条明确的文字检查，共 117 条：16 条 `auto`、74 条 `partial`、27 条 `judged`。原始规则的对应表和私有回归结果不进入此目录。

- `auto`：确定的文字模式、已识别图注的禁用内容、首页字段、文字量及配置明确的几何检查。每条均有合成 PDF 的正反测试。
- `partial`：执行机械初筛，同时对所有适用页面保留人判要求。没有命中初筛不等于通过。
- `judged`：不执行语义判断，只输出每页须看的项目。修订范围、受保护内容、冷读、独立验收、历史版本等过程证据也需要外部记录；单份 PDF 不能证明这些事情做过。

`generic` 是默认配置，适用于 Beamer、演示软件和其他导出工具。原表专属 V19 的尺寸、字号、导航和页脚要求仅在显式选择 `--profile v19` 后执行；其他模板不会被强制套用这些数值。未启用的配置项在 JSON 里写 `NOT_APPLICABLE` 和原因。要完整检查原表的 V19 数值规则，请选择 `v19`。

文字层覆盖首页标题、作者、日期及多余内容，审计标记、哈希、receipt、PASS/FAIL、内部版本与文件路径，过程陈述、合同用语、套话、口号、免责句、首次出现未定义的缩写，图注句数、分号和中点串、裸数字、耗时、数据版本，来源页脚、文字量和结尾页。合同、口号、免责句及缩写等语义相关项列为 `partial`，不能仅凭关键词确定违规。

布局初筛保留几何、文字角色、字号、行距、溢出、留白、栏平衡和对齐的测量，并增加图注锚点、语义间距候选、线段和节点、导航、页脚墨迹中心及结尾分区。复用了既有通用 V3 测量器的几何、可见文字、栅格和栏检测代码，没有移入历史页码、标签计分、私有校准样例或文件身份选择逻辑。混排文字改为逐字符匹配实际可见绘制记录，忽略透明或不可见文字。

## 阈值与适用性

原表已明确的尺寸、单位、间距区间和容差保存在 `rules.yaml`。没有冻结数值的项目保留空阈值并要求人判；不以正例的极值扩大阈值，也不从回归期望反推规则。

文字量默认上限为 180 单位：拉丁词或数字算一个，两个汉字算一个。这是本实现新增的可配置初筛上限，不冒称历史规则已冻结此数值。可用 `--word-budget 160` 修改；实际使用的阈值随命中证据记录。首页标题大小、作者行形态、图注位置等识别参数属于候选识别方法，不是新增内容规范。

PDF 点为 `1/72 inch`，TeX 点换算为 `TeX pt × 72/72.27`。光学像素坐标统一到 `1920×1080`。V19 普通页正文轨道为 `46–245 PDF pt`；其他模板只进行候选区域初筛。

## 证据边界

作者检测确认的是「有可识别的可见署名行」，不能核验身份。姓名形态、标题字号及日期格式的识别仍可能误报；只写在 PDF metadata 或未出现在 PDF 的 TeX `author` 字段不会补足署名。日期支持数字年月日和常见英文日期。

图注文字检查只覆盖已识别的图注。图形、表格与文字角色仍需按 `CAP-REQUIRED` 和 `ROLE-EXACTLY-ONE` 逐页核对；未识别的图注不能因没有文字命中而获最终通过。缩写释义按 PDF 阅读顺序初筛，后面的定义不能补救前面的首次使用；数学符号、领域知识和定义是否充分需要人判。

字号、间距、节点、栏宽及光学对齐多为 `partial`：PDF 缺少语义角色、容器边界、共享样式及源文件胶水，文字框也不是完整墨迹边界。源码只检查显式提供的单个 `.tex` 文件，不展开 `input`、执行宏或读取相邻私有文件。图内小字、裁剪后的矢量可见性和科学含义不得据这些初筛结果直接定案。

纯图片、无可提取正文的页面会触发 `TEXT-EXTRACTION-COVERAGE`，不会制造文字检查通过。本版不做 OCR。打不开、加密或测量出错的 PDF 会输出 `ERROR`；保留失败页面和错误，不缩小页数分母。

## 测试与维护

```sh
python -m pip install -r shared/presentations-validator/requirements-dev.txt
python -m pytest shared/presentations-validator/tests -q
```

测试只在临时目录生成小型合成 PDF，覆盖每条 `auto` 的正反例，以及普通 PDF、混排中文、不可见文字、可选 TeX、首次定义顺序、输入身份独立、错误恢复和重点 `partial` 初筛。测试标签独立写在测试中，不读取私有 oracle。

新增规则须同时登记 `id`、一句话规则、`mode`、`thresholds`、检测函数及适用配置。`auto` 必须增加正反合成例；`partial` 必须保留人判，不能把未实现部分改成自动通过。`COVERAGE.md` 说明各函数的检测边界。

本目录是独立工具，尚未接入 presentations 插件的安装或每版 deck 的正常交付入口；不表示该插件已强制执行本验收器。本次不改插件版本、生成层或发行状态。
