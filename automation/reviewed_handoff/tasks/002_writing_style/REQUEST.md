# 002 Writing Style — Request

整理当前 `writing-style` 能力，使其真正承担统一的成稿质量层：既保护事实和用户纠错，又让中文自然、少 AI 味、少翻译腔，英文科研文字保持专业但不模板化。

本任务不是新增“humanizer”技能，也不是做 AI 检测规避。重点是把已有 `writing-fidelity`、`chinese-prose`、`scientific-prose` 的职责、触发和协作写清，并用真实自然语言样例验证。

用户特别关心：中文优先、普通概念不堆英文、连贯段落优先、不要把审计/日志式提纲当正文、不要重复总结、不要机械三段式/三件套，同时必须保护数字、术语、路径、代码、引用和证据边界。
