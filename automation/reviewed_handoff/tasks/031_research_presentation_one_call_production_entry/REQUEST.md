# 031 Research Presentation One-Call Production Entry — Request

## Why this task exists

Stage 3 is now independently PASS: the normal Stage 2 gold selector / recipe can drive mature exact-CUHK scientific page families for model/equation, quantitative result, experiment design, negative result, medical comparison and next experiment, with real compile/render and task-local item-level visual evidence.

The remaining gap is product integration. The current `research-presentations` skill describes the intended workflow, but Stage 3 evidence still comes from an engineering integration generator. The program has not yet proved that one ordinary production invocation on user-supplied research material actually connects source ingestion, source-fidelity evidence mapping, storyline/page jobs, gold retrieval, Stage 3 layouts and exact CUHK rendering without calling benchmark helpers directly.

## Product outcome

Create the first bounded Stage 4 production integration: one normal `research-presentations` entry path should accept a public-safe engineering research input bundle and, in one invocation, produce a source-faithful deck plan, runtime gold/layout trace, exact CUHK `.tex + PDF`, rendered page images and task-local visual-review inputs.

This task proves the production orchestration surface and does not yet constitute full Stage 4 PASS. A later bounded Stage 4 task may still be required to close deck-rhythm review and the bounded visual repair loop before Stage 4 is marked complete.

## Scope

This task may:

- inspect and adapt the existing normal `research-presentations` production route rather than invent a benchmark-only parallel route;
- add the minimum shared orchestration needed to connect existing source-fidelity/deck-plan/gold/Stage-3/render components;
- use one repository-owned, public-safe engineering input bundle as regression input, provided it is passed through the same normal production entry surface and is explicitly excluded from Stage 5 holdouts;
- generate real exact-CUHK artifacts and a task-local Visual Review manifest;
- add deterministic tests proving the normal entrypoint, runtime trace and anti-helper boundary.

This task must not:

- use final Stage 5 statistics or medical-imaging holdout papers;
- hardcode the engineering input's title, notation, page count or layout into production logic;
- call the 027/030 benchmark generator as the production entrypoint;
- bypass normal gold selection with force IDs or score overrides;
- implement an unbounded autonomous repair loop;
- declare Stage 4, `PROGRAM_MATURE` or `ONE_SHOT_QUALITY_PASS` complete.
