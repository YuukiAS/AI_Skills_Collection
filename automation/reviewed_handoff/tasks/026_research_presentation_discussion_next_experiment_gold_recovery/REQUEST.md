# 026 Research Presentation Discussion / Next-Experiment Gold Recovery — Request

## Why this task exists

Stage 2 的主体能力已经由 025 建立：当前 9 条 production gold 均有 025 专用真实像素级 item-level `PASS` 与 identity binding；statistics / biostatistics 和 medical-imaging 两类 runtime probe 也已经通过正常 semantic compatibility 路径证明 `RUNTIME_SELECTED -> ACTUALLY_CONSUMED -> OUTPUT_AFFECTED`。

025 唯一没有关闭的是冻结合同里的 `discussion / next experiment` scientific-job coverage。现有 inspected/downloaded corpus 已按 Plan Revision 1 额外送审 20 个候选并用满有界额度，仍没有这一类页面达到 production-gold mature bar。025 已合法停在 `AWAIT_HUMAN_DECISION / REVIEW_LIMIT / REVISE`，其历史不得改写，也不得创建第三轮 review。

用户已明确授权一个新的、质量保持的 Stage 2 recovery：不降低 mature bar，不重做已经通过的 9 条 gold，只针对 `discussion / next experiment` 缺口做小规模、定向、rights-safe 的公开 source scouting / intake / real-pixel admission。

## Product outcome

本任务完成后，Stage 2 的 gold library 应至少新增一个真正成熟、与 `discussion / next experiment` scientific job 兼容的 production-gold composition record，并证明正常 selector / recipe 路径可以检索并消费它。这样 Stage 3 在生成讨论、开放问题或下一实验页面时，不需要重新回到无参考约束的自由布局。

## Scope

本 recovery 只允许：

- 保留并复用 025 已通过的 9 条 gold、selector、recipe builder、runtime probes、admission schema 与 evidence；
- 针对 `discussion / next experiment` 搜索少量公开科研演示资源；
- 只使用公开可访问、来源可定位、无私有数据或付费采购要求的 source；
- 对进入候选集的真实页面 materialize/render 实际 pixels，并使用当前 Bridge Kit / `gpt-5.6-terra` 做 item-level mature-bar admission；
- 记录 source/page/render identity、rights/reuse boundary、scientific-job compatibility、composition semantics 与 admission evidence；
- 将真正 item-level `PASS` 的新 record 加入 production gold，并验证正常 runtime selector 能为 discussion / next-experiment job 选择并消费它。

本 recovery 不允许：

- 改写 025 的 REVIEW/CURRENT/FINAL_REPORT；
- 重审或重做现有 9 条已通过 gold；
- 放宽 production-gold mature bar；
- 为了数量无界扩 corpus；
- 把 source pixels、logo、branding 或许可不明素材作为 production runtime 资产复用；
- 开始 Stage 3 renderer/layout/macros；
- 修改 canonical CUHK template；
- 修复 023；
- 运行最终 statistics / medical-imaging holdout；
- 修改 Terra core 或 Bridge Kit reviewer semantics。

本任务 PASS 只表示 Stage 2 coverage recovery 关闭。Planner 独立确认后，Stage 2 才可整体视为完成，并按 Program Goal 创建 Stage 3。
