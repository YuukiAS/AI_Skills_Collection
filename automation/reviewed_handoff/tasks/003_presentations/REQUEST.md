# 003 Presentations — Request

整理当前 Presentation 能力，使它真正服务于用户日常科研/技术汇报和可编辑 PPT 工作流，而不是把“学术”自动等同于 Beamer。

用户当前重点是：减少手工做 PPT；GPT/skill 先把故事、每页核心信息和证据组织清楚，再交给官方 Presentation/Slides 能力生成或编辑可编辑演示文稿，之后必须 render 并做视觉 QA。科研 deck 应按“为什么做 → 发生了什么 → 方法/机制 → 证据 → 局限 → 讨论 → 下一步”组织，一页一个核心信息，避免文献流水账、通用 bullet 模板和只有结构没有实际设计的 PPT。

中文演示文稿还应继承 writing-style 的“说人话、中文为主、少 AI 味、保真优先”规则。
